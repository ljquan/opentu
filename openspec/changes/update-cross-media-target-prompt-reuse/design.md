# Design: 跨媒体目标提示词复用

## Context

图片目标已有任务栏跟随、按目标草稿和虚化提示词状态机。视频、音频和文本生成结果使用不同画布元素结构，但都可以通过 `generationPrompt`、`aiPrompt` 和 `generationTaskId` 保存相同的轻量来源信息。

## Goals

- 图片、视频、音频和文本生成结果使用一致的虚化提示词交互
- 复用既有任务栏、草稿隔离和提示词取消状态机
- AI 生成视频和文本复用图片目标的任务栏跟随、临时关闭和永久关闭交互
- 普通内容不因正文或 URL 相似而被误判为 AI 生成结果
- 选区和视口高频刷新不触发无界历史扫描

## Non-Goals

- 不重新设计原位替换；单结果生成沿用既有 `replaceElementId` 语义，并补齐跨媒体一致性
- 不为普通手写文本或手动导入媒体推断提示词
- 不新增持久化提示词索引或复制媒体内容
- 本次不为音频新增跟随关闭菜单

## Decisions

### Prompt source

非图片目标按以下顺序读取提示词：

1. 元素上的 `generationPrompt` 或 `aiPrompt`
2. 元素上的 `generationTaskId` 对应任务的 `params.prompt`

图片继续兼容既有 `prompt` 字段、anchor 和结果 URL 回查。非图片目标不通过正文包含关系或媒体 URL 扫描历史任务，避免误匹配和 O(n) 选区开销。

### Target activation

单选元素解析出媒体类型和非空生成提示词后，复用现有目标草稿、定位和虚化提示词状态。任务栏切换到目标对应的 `image`、`video`、`audio` 或 `text` 类型。没有生成提示词的非图片元素返回普通选区流程。

### Suggestion lifecycle

沿用图片目标的既有状态机：空输入按空格或回车只采纳提示词而不提交；直接输入或操作其他控件取消建议；切换目标后重新按目标恢复；异步任务更新不得让已取消的旧建议回显。

### Text and video follow controls

图片、视频和文本目标显示同一组任务栏跟随控件。跟随开关只控制任务栏定位：关闭时任务栏回到底部，但目标绑定、按目标草稿和原位替换语义继续保留；重新开启后任务栏恢复到目标附近。

文本目标选择“本次只作上下文”或“始终只作上下文”后，任务栏解除原位替换绑定，并把当前生成文本正文作为 `selection.texts` 参与下一次生成。永久选择使用既有轻量元素标记，后续再次选择该文本时直接进入上下文模式。系统必须先通过生成元数据或明确任务 ID 确认 AI 来源，再提取正文，不能用正文反推生成来源。

视频目标选择“本次只作参考视频”或“始终只作参考视频”后，任务栏解除原位替换绑定，并继续通过现有 `selection.videos` 传递当前视频。永久选择复用同一轻量元素标记，后续再次选择该视频时直接进入参考模式。

目标状态键包含媒体类型，避免同一元素 ID 的类型变化复用旧状态。文本原位替换完成后触发选区刷新，以重新计算自动尺寸变化后的任务栏位置。

## Safety And Performance

- 画布元素只保存 prompt、task ID 等短字符串
- 当前仅保留一个选中文本目标的正文引用，不建立正文历史缓存
- 不把 Blob、base64 或完整任务历史写入元素
- 通过 task ID 点查任务，不读取最多数百或数千条历史记录后做模糊匹配
- 视口刷新继续通过 `requestAnimationFrame` 合并，并用运行序号丢弃过期异步结果
