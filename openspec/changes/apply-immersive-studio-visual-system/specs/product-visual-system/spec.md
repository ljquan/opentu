## ADDED Requirements

### Requirement: Immersive studio presentation
The product SHALL present its main user journey with a consistent charcoal
surface system, coral primary actions, violet selection states, and teal status
feedback while maintaining readable contrast and stable controls.

#### Scenario: Navigate across the product
- **WHEN** a user moves between home, account, creative center, works, workflows,
  model marketplace, and music station
- **THEN** navigation, controls, typography, and feedback SHALL remain visually consistent

### Requirement: Focused creation workspace
The canvas workspace SHALL keep the artwork as the primary surface while
providing a compact topbar, left tool rail, right context panel, and bottom AI
creation dock.

#### Scenario: Create on the canvas
- **WHEN** a user opens a board and starts an AI creation task
- **THEN** the canvas, creation input, parameters, and task state SHALL remain visible and operable

### Requirement: Responsive visual hierarchy
The visual system SHALL preserve readable text, non-overlapping controls, and
usable navigation on desktop and mobile viewports.

#### Scenario: Open on a narrow viewport
- **WHEN** the viewport width is 620 pixels or less
- **THEN** secondary panels SHALL collapse or move without obscuring primary content
