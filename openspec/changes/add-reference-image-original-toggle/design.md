## Context

任务栏设置位于 `AIInputBar.tsx`，目前仅在可绑定目标存在时显示。跟随及居中设置已有本地存储和变更事件模式。参考图处理分散在本地输入、素材库读取、缓存读取和生成任务执行中，必须避免仅改变 UI 而提交阶段仍发生压缩。

## Decisions

- 使用独立的共享偏好模块和统一存储键；沿用现有读取失败降级、写入失败保留会话值及设置变更通知模式。
- 用“保留原图”的正向含义：true 跳过可选有损压缩，false 沿用现有策略。用户确认默认关闭。首次上传前也显示任务栏设置入口。
- 接入所有实际共用链路，按入口读取偏好；运行中的单次转换使用开始时捕获的策略，不在压缩循环中动态改变。设置变更不恢复已经变换的输入。
- Base64 编码仅作为传输编码，开启保真后应保持解码后的字节及 MIME 不变。原图保真不等同于供应商输出能完全复刻纹理。
- 缓存的 AI 读取应允许明确覆盖压缩策略；原始缓存、UI 缩略图和 AI 请求图分开，不能用缩略图作为保真请求输入。
- 视频强制尺寸适配独立于可选 JPEG 压缩；不撤销供应商协议要求。合成画布截图的像素预算及裁剪编辑不属于原文件上传保真。
- 任务栏现有两个开关行为不变。使用现有 Switch 的可访问名称，不增加页面说明段落。

## Validation

- 偏好默认值、持久化、模块重载、存储不可用与通知测试。
- 超过 10MiB 的本地和素材库输入开启时保留原字节，关闭时仍走原压缩策略；25MiB 上限及无效文件保持拒绝。
- 超过 1MiB 的 data URL 和超过 2MiB 的缓存图开启时不经过 Canvas/JPEG 重编码；关闭时覆盖旧行为。
- 同步、异步和专用 adapter 路径至少覆盖一个成功请求及读取失败、取消、顺序、远程 URL 直传兼容行为。
- 视频尺寸适配回归；类型检查、相关静态检查和构建。按用户规则不默认执行页面交互或真实付费生成。
- 实施后在现有 `docs/` 中记录 QA 和使用限制，真实测试完成前不记录通过。
