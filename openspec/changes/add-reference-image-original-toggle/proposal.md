# Change: 在任务栏设置中增加参考图保真开关

## Why

参考图上传超过 10MiB 时会被重新编码；统一缓存读取和生成请求转换还分别存在 2MiB 和 1MiB 的有损压缩条件。用户无法选择保留面料纹理等细节，单独取消上传压缩也不能保证实际请求使用原图。

## What Changes

- 在截图对应的任务栏设置面板中增加“保留原图”开关，与任务栏跟随、点击目标后自动居中使用一致的控件样式。
- 开启时跳过公共参考图输入、缓存读取和提交转换中的可选有损压缩；关闭时沿用现有体积优化策略。压缩通常减小传输及缓存体积，但不承诺端到端耗时必然缩短。
- 本地保存偏好并同步当前页面；默认关闭，按用户确认优先减小体积，用户可主动开启保真。
- 公共参考图组件、底部 AI 输入栏和共用请求转换遵循同一偏好，适用于使用这些路径的各生图模型，不限定 GPT Image。
- 保留类型、数量及 25MiB 上传校验；保留视频模型明确要求的尺寸适配，并将可选体积压缩纳入开关。
- 只影响后续处理，不重写已有缓存、任务结果或历史素材；已经压缩的图片需重新导入原文件。

## Impact

- Affected specs: `ai-input-generation`, `image-generation`.
- Affected code: AIInputBar 设置与上传入口、ReferenceImageUpload、统一缓存的 AI 图片读取、media-executor 参考图物化、video-reference-image-utils，以及实际调用这些公共路径的入口。
- 不新增依赖、接口、环境变量或数据迁移；不改变生成结果的 `quality`、`output_compression` 或预览缩略图策略。
- 边界：供应商仍可能处理输入；原图请求体更大；供应商限制不能由此开关绕过。仅共享压缩路径受控，独立 `/workflow` 原图存储保持现状。

## Approval

用户已确认默认关闭并继续实施本方案。依据 `openspec/AGENTS.md` 的新增能力审批要求执行。
