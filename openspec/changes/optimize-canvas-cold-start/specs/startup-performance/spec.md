## ADDED Requirements

### Requirement: 首次进入画布的资源边界必须包含实际画布

系统 SHALL 分别报告 Web 启动壳层和首次进入实际画布所需的静态资源依赖，后者 MUST 包含自动加载的画布入口及其全部静态依赖。系统 SHALL 同时报告依赖总量与单资源大小。

#### Scenario: 启动壳层很小但画布依赖仍然很大

- **WHEN** 启动壳层之后立即加载画布入口
- **THEN** 构建检查将该画布入口及其静态 JS/CSS 依赖计入画布首次加载报告
- **AND** 不会仅凭 bootstrap 预算通过而判定实际画布加载已经优化

### Requirement: 画布可选操作按使用场景加载并保留恢复能力

系统 SHALL 允许用户在未使用生成和工具操作时加载普通画布，而不因这些可选操作的静态引用提前下载其执行模块。系统 MUST 在用户首次触发操作或检测到需要恢复的任务时可靠加载相应模块。

#### Scenario: 空白画布没有待恢复任务

- **WHEN** 用户首次打开空白画布且未触发生成或工具操作
- **THEN** 可选生成和工具执行模块保持按需加载
- **AND** 基础画布渲染、保存、撤销和缩放正常

#### Scenario: 首次触发可选操作

- **WHEN** 用户首次调用尚未加载的生成或工具能力
- **THEN** 系统加载所需运行时并执行操作
- **AND** 加载失败有明确提示，重新触发不会因加载过程重复提交生成任务

#### Scenario: 存在待恢复生成任务

- **WHEN** 页面启动时检测到需要恢复的持久化任务
- **THEN** 系统唤醒所需运行时并沿用已有恢复和去重机制
- **AND** 恢复期间的离开保护仍然有效

### Requirement: 启动性能验收必须验证画布可交互

系统 SHALL 以相同网络与缓存条件下实际画布挂载并完成交互验证作为启动优化的验收依据，单独记录启动遮罩结束时间。

#### Scenario: 遮罩已经结束但画布未挂载

- **WHEN** 启动遮罩消失而画布仍未可交互
- **THEN** 系统不得将遮罩消失时间报告为画布可操作时间
- **AND** 性能验证继续等待实际画布并检查基础交互
