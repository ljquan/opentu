已接入 `/workflow/batch-generation`；未勾选项可能已有局部实现，但不代表其完整验收矩阵已通过。PDF 目前提供文本候选、页预览、手动裁图与可选识别，复杂排版需要人工确认。IndexedDB 使用批次/轮次/工作项/控制四个事务存储；导入记录随批次保存，尚未完成独立分页 checkpoint。跨标签页使用持久 owner 与单次 ticket，不是完整可过期租约实现。原路由的 Request ID 查询可用；带 remoteId 的异步恢复暂不支持，保持 uncertain。资源回收仅清理被删除批次的独立资源记录，不清除共享缓存。
