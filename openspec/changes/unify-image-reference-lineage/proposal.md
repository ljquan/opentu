# Change: 统一参考图来源与生成结果布局

状态：用户已确认对话中的效果方案并回复“可以”，授权本地实施和测试。

## Why

普通生图根据选中图片横竖比决定结果方向，且单图可能替换来源；上传参考图仅在输入栏，结果缺少可追溯的画布来源。需要统一为有参考图向右派生、无参考图向下新增。

## What Changes

- 根据本次提交的实际参考图识别画布来源，不依赖等待期间的选择或历史选择。
- 发送时将画布中缺少的参考图固化到本地缓存并加入画布，重复发送复用已有来源；全部参考图准备成功且画板未切换后才写入画布。
- 来源整体右侧放置结果，同来源后续批次在同列向下避让；从结果继续生成则延伸下一列。无参考图沿独立创作区域向下放置。
- 占位与结果使用同一位置，每个批次图片结果均保留实际来源连线。重试继续使用原有来源和占位。
- 普通图片生成不覆盖原图；保留显式语义主体替换、画框内生成和其他媒体的既有行为。

## Impact

- Affected specs: 新增 `image-reference-lineage`。
- Affected code: 主输入提交、参考图准备服务、方向布局、批次来源连线和自动插入回归。
- 无数据库版本或供应商协议变更，复用画布元素、canvasAssociations、anchorId 和缓存服务。
- 仅本地代码和逻辑测试，默认不做页面测试、付费生成、提交或推送。

## Acceptance

画布单图/多图、上传/混合引用、重复发送、从结果继续生成、无引用、并发占位避让、准备失败和画板切换均有可重复逻辑测试；原始图片及位置保留，所有批次结果可追溯。完成类型、静态检查和构建，更新现有 DOC/QA。
