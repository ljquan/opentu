## ADDED Requirements

### Requirement: 异步媒体任务必须持久化恢复凭据

系统 SHALL 在向供应商提交异步媒体请求之前持久化客户端请求 ID、执行阶段和供应商路由，并在收到远程任务 ID 后等待其成功落盘再开始轮询。

#### Scenario: 远程任务 ID 在轮询前持久化

- **GIVEN** 用户提交异步视频、音频或图片任务
- **WHEN** 供应商返回远程任务 ID
- **THEN** 系统必须先持久化远程任务 ID、轮询阶段和原供应商路由
- **AND** 持久化成功后才开始查询任务状态

#### Scenario: 刷新发生在提交响应返回前

- **GIVEN** 客户端请求 ID 已持久化
- **AND** 请求可能已经到达供应商
- **WHEN** 页面在远程任务 ID 落盘前刷新
- **THEN** 系统必须优先使用客户端请求 ID查询原请求
- **AND** 不得自动创建第二个可能重复计费的任务

### Requirement: 页面刷新后必须恢复可恢复的异步媒体任务

系统 SHALL 在启动时识别拥有有效恢复凭据的未完成任务，并使用原供应商路由继续追踪，而不是将其直接标记为页面刷新中断。

#### Scenario: 轮询阶段刷新

- **GIVEN** 异步媒体任务已保存远程任务 ID并处于轮询阶段
- **WHEN** 用户刷新或重新打开页面
- **THEN** 系统使用保存的远程任务 ID和路由继续轮询
- **AND** 不重新提交生成请求

#### Scenario: 供应商不支持安全找回

- **GIVEN** 任务只有客户端请求 ID且没有远程任务 ID
- **AND** 原供应商不支持请求 ID查询或幂等恢复
- **WHEN** 页面恢复任务
- **THEN** 系统不得自动重新提交
- **AND** 必须提示用户确认后再重试

### Requirement: 恢复完成的媒体必须继续进入画布

系统 SHALL 将刷新后恢复完成的任务按正常完成任务处理，包括结果缓存、完成事件和自动插入画布，并保证幂等。

#### Scenario: 恢复后自动插入

- **GIVEN** 任务启用了自动插入画布
- **AND** 任务在页面刷新后恢复并完成
- **WHEN** 结果已经持久化且画布就绪
- **THEN** 系统将媒体插入原目标画布或有效锚点位置
- **AND** 插入成功后持久化已插入标记

#### Scenario: 插入前再次刷新

- **GIVEN** 任务已经完成并保存结果但尚未插入画布
- **WHEN** 页面再次刷新
- **THEN** 系统在画布就绪后继续插入该结果
- **AND** 不丢失生成结果

#### Scenario: 已插入任务再次恢复

- **GIVEN** 任务已持久化 `insertedToCanvas=true`
- **WHEN** 页面刷新并恢复任务历史
- **THEN** 系统不得将同一结果重复插入画布
