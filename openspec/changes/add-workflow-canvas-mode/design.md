# Design: 工作流画布模式

## Decisions

1. 复用同一个 Drawnix/Plait Board，在普通文档与工作流文档之间切换；切换前原子保存当前快照。
2. 工作流节点复用现有 Frame，并在 Frame 元素上保存版本化输入口和输出引用元数据。
3. 工作流边使用独立、可持久化的元素类型；纯图规则在执行 Plait transform 前校验。
4. 输入连接保存上游输出引用，不复制图片或视频。更换上游输出时连接保持并实时解析新引用。
5. 异步生成任务捕获 `documentId + frameId + region`，模式切换后仍回写来源文档。
6. 工作流专属实现集中在 `workflow-mode/`，目录外只保留必要接入代码。
7. 2026-09-19 用户补充：左侧输入口也可发起连线，两个输入口可以相连。边增加可选 `sourcePortId`，省略时兼容原右侧输出口；数据方向由发起端指向接收端，仍传递源节点当前选定的输出。每节点最多一条出边、每输入口最多一条入边及无环约束保持不变。
8. 2026-09-19 用户补充：输入口由工作流节点层提供加减控制。加号追加新端口，减号只允许删除未连接且非最后一个端口；所有端口 ID 保持稳定。节点尺寸复用现有 `withFrameResize`，工作流插件负责在尺寸变更后重算端口和连线几何。
9. 2026-09-19 用户补充：工作流连线保持锁定以避免被拖动破坏，但由工作流连接层提供透明加宽命中路径。选中连线后可通过工具栏删除按钮或 `Delete`/`Backspace` 删除，删除只移除边并保留两端节点及端口数据。

## Failure Handling

- 损坏或旧卡片式存储初始化为空工作流，不触碰普通文档。
- 保存失败保留当前内存态和上一次有效持久化值。
- 自连接、循环、重复占用输入口和失效拖拽均不修改现有图。
- 输出元素删除后连接保留为未解析输入，用户可以重新指定输出。
- 已连接或最后一个输入口的删除操作被拒绝，不静默删除边或端口。
- Frame 缩放失败时保留原边界和连线，最小尺寸由现有 Frame resize 规则保证。
- 异步任务完成时若来源文档未激活，结果进入来源文档待恢复队列，不插入当前普通画布。

## Validation

- 纯模型和 transforms 使用 Vitest 做 TDD。
- 模式切换、生成路由和持久化做集成测试。
- 使用真实浏览器验证桌面/移动端添加节点、连接、编辑、切换和刷新。
- 运行 web typecheck、目标 ESLint 和生产构建。
