# SVG 源文件适配实现说明

## 已确认目标

用户确认按文件已有内容提供两项能力：编辑真实矢量元素；播放文件已有且浏览器支持的动画。实现只处理已有文件，不修改模型、分组、生成参数或提示词，不新增生成请求。

## 文件识别与读取

- 工具入口只为 SVG data URL 或带 `.svg` 的地址建立候选；最终能力取决于原始 XML 内容，型号名称不能赋予能力。
- 从现有统一缓存读取原始 Blob；本地虚拟缓存缺失时提示重新导入，不使用 PNG 缩略图冒充原文件。外部原图读取省略认证和 referrer，限制 20 秒、2 MB。
- XML 必须为 SVG 命名空间，最多 2000 个节点。使用元素白名单，拒绝脚本、事件属性、foreignObject、实体、外部资源、外部字体及不支持的样式。位图即使位于 defs 中，也不能被标为纯矢量拆分。

## 静态部件编辑

- 使用现有图片节点承载独立 SVG 片段，保留真实路径和资源定义。现有 PenPath 无法保真表示任意复合路径，因此不转换为原生路径锚点。
- 浏览器原生 `getBBox/getCTM` 提供几何数据。按源顺序拆分 path、基本形状、text、use；普通 g 遍历子图形，带透明度、滤镜、蒙版或裁切的组作为整体保留。引用、渐变及其定义继续保存在片段内。
- 在移除 CSS 选择器上下文前冻结受支持的计算样式。依赖视口的几何、嵌套 SVG、无法保留的样式、根合成效果、用户坐标滤镜等拒绝转换并保留原图。转换最多产生 200 个部件。
- 保留原图片，在右侧空白位置放置副本；考虑 viewBox、原图宽高比和留白。旋转、3D 变换或非 100% 画布透明度需先恢复再转换。裁切式 preserveAspectRatio 暂不拆分。
- 部件可独立选择、移动和缩放。只有统一且直接适用的填充/描边才提供颜色字段；渐变、引用及复杂文字不冒充可直接重着色。无子节点的简单 text 才提供文字输入。文字和描边变化后重新测量，不按旧尺寸裁切。
- 所有片段先验证并写入缓存，再一次历史批次插入。失败撤销已插入节点，原节点始终保留；旧内容继续可供撤销。

## 自带动画

- 识别有正时长、可由时钟启动的原生 SMIL，及被真实元素引用的 CSS keyframes。事件驱动或不支持的动画不宣称可播放。含动画定义的源文件当前不拆为静态部件。
- 使用独立 iframe 显示原 SVG，sandbox 仅含 `allow-same-origin`，无 `allow-scripts`。CSP 禁止脚本与网络，只允许文件自身准确哈希匹配的样式和内嵌位图。
- 父页面通过原生 `pauseAnimations/unpauseAnimations` 和 `Document.getAnimations` 控制已有时间轴，暂停/继续不改写 SVG，不添加动画。
- 原图片继续负责既有加载、缓存和错误状态。动画文档就绪后才显示覆盖层并开放控制；失败保留原图。默认尊重系统减少动态效果偏好，后台或离屏暂停；回到可见状态按用户选择恢复。
- `svgPlayback` 保存用户的播放/暂停选择；运行时就绪信息保存在 WeakMap，不进入文件。源变化、卸载和画板切换释放监听、iframe、observer，并中止过期操作。

## 持久化和兼容

现有图片节点新增可选 `svgPlayback` 和 `svgVectorPart`。后者包含版本、原 SVG 缓存地址、原节点 ID、片段标识、名称及适用的填充/描边/文字值。新字段缺失时仍按旧图片显示，无数据库迁移。

原节点保留生成任务信息。副本只记录原节点关联，不复制 generationTaskId，避免将部件重复登记为生成结果。画布内嵌媒体和现有同步的本地媒体收集同时保存片段与原文件，即使用户后续移除原节点，导出仍能带上原文件。实现没有执行 GitHub 同步或远程写入。

不新增依赖或配置。禁用/移除 SVG 工具和覆盖层即可回到图片显示路径；已创建片段本身仍是普通可显示 SVG 图片节点。

## 验证边界

逻辑测试覆盖安全分类、原文件读取、几何数据映射、实际画布历史、缓存失败、画板切换、编辑及媒体恢复。jsdom 中的几何和原生动画 API 均显式模拟，不能证明浏览器的真实渲染、动画流畅度或任意渠道 SVG 的保真度。实际命令和结果记录在 `validation.md`。
