# Change: OpenTu 版本更新后自动获取模型

## Why
用户希望每次升级 OpenTu 后自动获取已适配的新模型，不再手动点击获取。2026-11-05 用户明确选择按应用版本触发，替代此前定期刷新提案。

## What Changes
- 新版本启动后在后台对已启用、凭证已保存且支持现有模型发现协议的渠道获取一次模型；同版本成功后不再重复获取。
- 没有成功版本标记的历史配置首次运行时补查一次。无 Key、禁用、不支持模型接口或尚未通过兔子账户验证的渠道跳过；待配置就绪后补查。
- 仅成功提交目录后记录版本；失败保留旧目录，下次启动重试，不增加轮询、定时重试或焦点刷新。
- 新发现的模型通过现有类型分类和适配链路加入选择器；保留已有取消勾选、手动绑定、当前/默认模型及任务路由。
- 以当前凭证的模型接口结果为准，广场仅补充元数据，不宣称能够自动适配全新接口协议。
- 新增可选目录字段 lastAutoRefreshVersion；缺失表示尚未执行，补齐配置规范化、存取、重载与备份恢复兼容。
- 同页面重复挂载/配置通知合并；异步结果提交时核验配置仍有效，避免覆盖新 Key 或已删除渠道。

## Impact
- Affected specs: runtime-model-discovery。
- 影响模型目录存储、应用启动和模型发现；不改变手动获取入口。
- 独立分支实现，不混入下载入口 PR #326。

## Approval
用户于 2026-11-05 明确要求“每次更新版本的时候，自动获取一下就好”，按本提案收窄后的范围实现。
