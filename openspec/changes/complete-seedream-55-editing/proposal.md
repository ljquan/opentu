# Change: 补齐 Seedream 5.5 连续编辑与富文本分层

状态：2026-11-15 用户确认“按此方案实施”，授权本地实现和测试。方案已通过 OpenSpec 严格校验。

## Why

Seedream 5.5 普通生成已走原生 v3，但连续编辑缺少专用入口，现有分层入口仍优先本地推理并固定回退到 5.0 Pro，公共响应校验器最多接受 16 个前景图层，且没有保留 OCR 结果。仅增加请求字段不能实现完整功能。

## What Changes

- 增加 Seedream 5.5「继续编辑」入口：所选结果优先作为下一轮参考图，继承历史模型/供应商及适用参数；历史参考图去重后保留，总数最多 10 张。超过上限时显示提示并允许用户调整，不静默丢图。回填后由用户填写修改要求并发送；不自动生成。原「再次生成」保持按原条件重做。
- 为 Seedream 5.5 增加分层设置入口，明确选择原生 v3 分层，前景上限可选 1–99，默认保留 16；请求 max_images 为前景上限 + 1，包含底图，提供数量及计费提示。保留现有本地分层与旧模型路径，不把它们的上限统一改为 99。
- 支持文字识别开关，启用时发送 layer_decomposition_options.text_recognition=true；解析并保存全文、逐行边界框、样式片段，随图层、画板和 manifest 保留。
- 有有效 OCR 的文字图层提供「转换为可编辑文字」：按底图坐标映射到画布，近似还原字体、颜色和可支持的样式；原图层保留且转换时隐藏，避免双重显示，支持撤销。未知字体使用现有字体回退；字号根据行框估算，阴影和半透明只保留识别标记，不伪造精确数值。
- 透明 PNG、URL 返回、默认无水印及现有比例选项继续沿用。本次不恢复已撤回的棋盘格，也不裁剪原图。

## Impact

- Affected specs: image-generation, semantic-layer-decomposition。
- Affected code: 图片任务回填、工具栏、分层入口、provider/contract/types、缓存与画布图层元数据、文字节点转换、manifest。
- 初始授权范围为本地实现和测试；2026-11-15 用户追加真实测试及创建新 PR 授权。本次 PR 仅提交 OpenTu 改动，不部署或合并，不包含独立 Tuzi API 补丁。
- 不新增凭据、数据库迁移或服务端部署；原生分层失败不能自动切换模型或重新发起收费生成。

## Acceptance

1. 从多图结果中选定哪张，就用哪张继续编辑；历史任务不被改写，参考图总数上限与供应商绑定正确。
2. 原生分层 1/16/99 前景分别发送 max_images=2/17/100；100 张有效产物可以完整校验、缓存、排列、存档，旧本地路径仍限制 16。
3. OCR 开关正确传输；缺失或无效的可选 OCR 不使有效图片丢失；无 OCR 的图层不能误转换为文字。
4. 多行、多样式、缩放/旋转坐标正确；转换保留可恢复的原图片层，撤销与重复操作不产生重复可见文字。
5. 源图删除/切换画板、取消、缓存失败、请求失败不得误写其他画板或重复提交；原生可信结果不伪装成已进行本地像素质量验证。
6. 运行相关测试、Drawnix/Web 类型检查及适用构建；更新现有 docs/qa-seedream-5-5.md，区分本地验证与上游实测。

## GET 恢复补充（2026-11-15）

真实验收确认线上结果 GET 只返回图片链接，连接中断后丢失分层位置及 OCR。用户要求继续后，补齐本地恢复链路：

- Seedream 5.5 原生提交为可信 Tuzi 地址生成请求 ID，明确禁止 POST 重放。自动恢复与弹窗中的“获取已有结果”只执行 `GET /v1/images/generations/result?request_id=...`，使用提交时捕获的供应商配置。
- 查询每次最多 15 秒、总计最多 15 分钟，间隔 5 秒；验证请求 ID 和业务状态。旧记录缺元数据时明确报错，不猜测位置、不重复生图。
- 恢复句柄只存在当前弹窗内存中，不持久化密钥；关闭/刷新不会自动续查。恢复插入仍校验原画板和源图。
- Tuzi 后端快照实验曾在独立工作树验证；用户随后要求撤回，相关改动已备份后撤销，不在本 PR 范围。前端只在 GET 返回完整元数据时恢复，URL-only 结果明确报错。
- 本次不修改 Tuzi API，也不新增图片下载代理或 Nginx 配置。2026-11-16 曾追加实现同源图片下载，用户随后明确因需修改 Nginx 而撤回该项；线上完整分层 GET 恢复仍依赖服务端元数据，跨域图片缓存失败保留为已知限制。
- 本轮只做本地测试，不新增收费生成、部署或 PR 更新；历史未保存的元数据不可补录，签名 URL 仍受原有效期限制。
