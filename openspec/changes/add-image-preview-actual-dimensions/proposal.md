# Change: 图片预览显示实际尺寸

## Why

统一图片预览缺少当前图片的像素尺寸，用户只能回到任务栏确认上游实际结果，且从任务栏和画布进入预览时信息不一致。

## What Changes

- 在统一图片预览工具栏显示图片任务结果的实际宽高。
- 任务列表预览直接透传任务结果尺寸；画布预览通过已持久化的生成任务关联读取同一数据。
- 缺失或非法尺寸时不显示，不使用请求尺寸或画布缩放尺寸兜底。
- 保持视频、音频及现有预览操作不变。

## Impact

- Affected specs: `media-preview`
- Affected code: 统一媒体预览、任务列表预览数据映射、画布媒体预览和任务手动插入关联
