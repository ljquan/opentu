# Change: 新增 Tuzi 固定渠道与按需模型发现

## Why

当前工作流配置把 Tuzi 当作普通可编辑渠道，API Key 只能保存一个，模型需要手动维护。用户希望固定使用 Tuzi 接口、保存多个 Key 并明确选择当前使用 Key，同时从 Tuzi pricing 榜单按需获取热门模型或完整模型列表。

## What Changes

- 增加固定 Tuzi 渠道类型，接口地址固定为 `https://api.tu-zi.com`，用户不能修改协议或地址。
- 支持多个 API Key，显示脱敏标识并由用户手动选择一个当前 Key；新请求使用当前 Key，已提交任务继续使用其路由快照。
- 增加“获取热门 200”和“获取全部模型”两个明确按钮。未点击前不请求 pricing；热门模式按 `hot_rank` 取前 200，全部模式保留接口返回的完整模型列表。
- 获取结果只更新固定渠道的模型候选，不覆盖用户已有能力/脚本配置；保存后可继续手动调整能力映射。
- 对 pricing 请求增加超时、响应结构、数量和热度排名校验；失败不清空已有模型。

## Impact

- 影响工作流配置页、渠道类型与本地配置持久化、模型选择和 Tuzi pricing 读取。
- 不改变普通渠道、已有任务路由或供应商请求协议。
- 默认不自动获取、不自动轮换 Key、不自动替换模型。
