## ADDED Requirements

### Requirement: 系统必须提供任务灵宠

系统 SHALL 在左侧工具栏垃圾桶按钮正上方显示灵宠设置入口，并在画布上显示可移动的内置任务灵宠，根据统一任务队列的当前状态展示文字和动作反馈。

#### Scenario: 工具栏设置入口

- **WHEN** 左侧工具栏完成渲染
- **THEN** 灵宠设置入口紧邻垃圾桶按钮上方
- **AND** 入口尺寸与工具栏按钮轨道保持稳定
- **AND** 点击入口直接打开设置对话框的任务灵宠页
- **AND** 关闭灵宠显示后设置入口仍然可用

#### Scenario: 默认画布位置

- **GIVEN** 灵宠已启用且没有已保存位置
- **WHEN** 画布渲染完成
- **THEN** 灵宠本体显示在画布右下区域
- **AND** 灵宠本体与工具栏设置入口是两个独立元素

#### Scenario: 拖动灵宠

- **WHEN** 用户用指针拖动灵宠本体
- **THEN** 灵宠跟随指针并按移动方向展示 running-left 或 running-right 反馈
- **AND** 拖动事件不会触发画布绘制、平移或选择
- **AND** 灵宠中心点被夹取在当前视口安全区域内
- **AND** 松手后才持久化最终归一化位置

#### Scenario: 没有活动任务

- **GIVEN** 灵宠已启用且没有匹配的活动任务
- **WHEN** 画布渲染完成
- **THEN** 灵宠显示为低干扰 idle 状态
- **AND** 不显示历史任务完成或失败提示

#### Scenario: 任务开始执行

- **GIVEN** 灵宠已启用且任务类型已被选择
- **WHEN** 统一任务队列创建或开始执行任务
- **THEN** 灵宠展示开始提示
- **AND** 动作状态映射到 wave 或 running

#### Scenario: 已存在活动任务

- **GIVEN** 页面加载时已有匹配的活动任务
- **WHEN** 灵宠从共享任务快照初始化
- **THEN** 灵宠直接展示对应的活动状态
- **AND** 不把历史任务误报为刚刚开始

#### Scenario: 任务状态变化

- **WHEN** 任务进入 submitting、processing、polling 或 downloading 阶段
- **THEN** 灵宠分别展示忙碌、等待或检查结果状态
- **AND** 不创建新的任务状态源或轮询

#### Scenario: 任务完成或失败

- **WHEN** 任意任务事件携带的匹配任务进入 completed 或 failed 状态
- **THEN** 灵宠展示对应完成跃起或失败抖动状态
- **AND** 气泡提供可理解的终态摘要
- **AND** 不依赖 taskCompleted 或 taskFailed 专用事件一定存在

### Requirement: 用户必须能够配置提醒方式和任务类型

系统 SHALL 提供灵宠显示、动作提醒、语音播报和文本/生图/生视频任务类型的独立设置。

#### Scenario: 首次使用默认值

- **GIVEN** 本地不存在灵宠偏好
- **WHEN** 用户首次打开应用
- **THEN** 灵宠默认显示并开启动作
- **AND** 语音默认关闭
- **AND** 文本、生图、生视频任务默认全部启用

#### Scenario: 只启用某一种任务

- **GIVEN** 用户只启用了生图任务提醒
- **WHEN** 文本、图片和视频任务分别发生状态变化
- **THEN** 灵宠只响应图片任务

#### Scenario: 文本类型映射

- **GIVEN** 用户启用了文本任务提醒
- **WHEN** `TaskType.CHAT` 任务发生状态变化
- **THEN** 灵宠将其作为文本任务响应
- **AND** 不读取任务提示词进行分类

#### Scenario: 只启用语音或动作

- **WHEN** 用户独立切换动作和语音开关
- **THEN** 系统按当前组合提供反馈
- **AND** 关闭其中一种方式不影响另一种方式

#### Scenario: 功能被关闭

- **WHEN** 用户关闭灵宠显示
- **THEN** 灵宠与气泡从画布隐藏
- **AND** 系统取消任务事件订阅和计时器并停止发起后续语音
- **AND** 不通过全局取消操作打断已经开始的其他朗读

### Requirement: 灵宠偏好必须安全持久化

系统 SHALL 将版本化的非敏感灵宠偏好并入现有 `AppSettings` 持久化链路，并在配置或存储异常时安全回退。

#### Scenario: 刷新后恢复

- **WHEN** 用户修改灵宠设置并刷新页面
- **THEN** 系统恢复有效的显示、动作、语音、任务类型和位置偏好

#### Scenario: 旧版偏好迁移

- **GIVEN** 本地保存的是不含位置的 v1 灵宠偏好
- **WHEN** 系统读取偏好
- **THEN** 系统保留原有开关和任务类型
- **AND** 补充默认画布位置并升级为 v2

#### Scenario: 偏好为空或损坏

- **GIVEN** 本地偏好为空、JSON 损坏、字段类型错误或版本不受支持
- **WHEN** 系统读取偏好
- **THEN** 系统使用完整默认值
- **AND** 不阻塞应用启动

#### Scenario: 本地存储写入失败

- **WHEN** 浏览器拒绝灵宠偏好写入
- **THEN** 当前页面仍应用用户选择
- **AND** 不影响任务执行或其他设置

#### Scenario: 环境备份与数据清理

- **WHEN** 用户导出环境备份
- **THEN** 非敏感灵宠偏好包含在备份中
- **AND** 导入备份时通过现有设置规范化恢复有效偏好

### Requirement: 语音提醒必须复用本地浏览器能力

系统 SHALL 复用现有 TTS 语音选择和播放参数，通过浏览器语音合成播报短任务摘要。

#### Scenario: 语音可用

- **GIVEN** 用户已启用语音且浏览器支持语音合成
- **WHEN** 匹配任务开始、完成或失败
- **THEN** 系统使用现有语音、语速、音调和音量设置播报摘要
- **AND** 不上传播报文本或申请麦克风权限

#### Scenario: 语音不可用或播放失败

- **GIVEN** 浏览器不支持语音合成或阻止播放
- **WHEN** 灵宠尝试播报
- **THEN** 系统静默降级为动作和文字气泡
- **AND** 不将语音问题标记为任务失败

#### Scenario: 画布语音正在播放

- **GIVEN** 浏览器语音合成正在播放画布朗读或其他语音
- **WHEN** 灵宠产生可播报事件
- **THEN** 灵宠跳过本次语音播报并保留动作和文字反馈
- **AND** 不调用全局取消操作打断既有语音

#### Scenario: 进度频繁变化

- **WHEN** 同一任务在短时间内多次更新进度
- **THEN** 系统不逐次播报进度
- **AND** 只更新去重后的视觉进度提示

### Requirement: 并发任务提醒必须有界且去重

系统 SHALL 在多个任务并发更新时保持有界状态，并对重复事件和密集终态进行去重或聚合。

#### Scenario: 多个任务同时进行

- **WHEN** 多个匹配任务并发更新
- **THEN** 灵宠优先展示最近活跃任务的状态
- **AND** 详细任务状态仍由统一任务队列提供

#### Scenario: 多个任务密集完成

- **WHEN** 多个任务在聚合窗口内完成或失败
- **THEN** 系统按完成数和失败数生成一个聚合提示
- **AND** 不创建无界语音队列

#### Scenario: 重复终态事件

- **WHEN** 同一任务通过 taskUpdated 和终态专用事件重复到达
- **THEN** 系统只提醒一次

#### Scenario: 同一任务重试

- **GIVEN** 任务重试时复用原任务 ID 并产生新的 startedAt
- **WHEN** 重试运行再次完成或失败
- **THEN** 系统将其识别为新的运行并正常提醒一次

#### Scenario: 任务结束或被删除

- **WHEN** 活动任务完成、失败、取消或删除
- **THEN** 系统释放该任务的进度记录
- **AND** 固定上限的终态去重记录淘汰最旧条目

### Requirement: 灵宠必须兼容响应式布局和减少动态效果

系统 SHALL 在桌面和移动视口保持灵宠、气泡与左侧工具栏控件可用，并尊重系统减少动态效果偏好。

#### Scenario: 移动端或窄视口

- **WHEN** 画布宽度进入移动端布局
- **THEN** 工具栏设置入口仍位于底部操作区且不改变工具栏宽度
- **AND** 画布灵宠位置按当前视口重新夹取
- **AND** 气泡根据剩余空间选择展开方向并限制在可用视口内
- **AND** 文本不溢出或遮挡相邻工具按钮

#### Scenario: 用户减少动态效果

- **GIVEN** 系统启用了 `prefers-reduced-motion: reduce`
- **WHEN** 灵宠状态变化
- **THEN** 系统停用循环位移和抖动动画
- **AND** 保留静态状态、文字和可选语音反馈
