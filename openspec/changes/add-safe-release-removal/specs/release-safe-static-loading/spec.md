## ADDED Requirements

### Requirement: 历史发布版本必须可安全清理
系统 SHALL 提供按明确版本号删除历史发布产物的管理命令，并在删除前保护所有正在提供服务的版本。

#### Scenario: 删除未激活的历史版本
- **WHEN** 管理员指定一个存在且未被预发布或生产环境使用的版本
- **THEN** 系统删除该版本的远端发布目录
- **AND** 后续版本列表不再显示该版本

#### Scenario: 拒绝删除正在使用的版本
- **WHEN** 管理员尝试删除当前预发布或生产版本
- **THEN** 系统拒绝删除
- **AND** 对应版本目录和符号链接保持不变

#### Scenario: 拒绝不安全的版本参数
- **WHEN** 删除参数不是标准三段式版本号
- **THEN** 系统在执行远端命令前终止操作

#### Scenario: 预览删除操作
- **WHEN** 管理员使用 dry-run 删除历史版本
- **THEN** 系统报告计划删除的版本
- **AND** 不改变远端文件

### Requirement: 撤回版本必须在版本记录中明确展示
系统 SHALL 在公开版本记录中标记已撤回版本，且不得提供指向已删除产物的访问链接。

#### Scenario: 查看已撤回版本
- **WHEN** 用户打开包含已撤回版本的版本记录页
- **THEN** 页面显示撤回状态和原因
- **AND** 页面不显示进入该版本的链接
