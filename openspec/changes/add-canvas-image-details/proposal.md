## Why

用户选中画布图片后，需要在图片顶部工具栏直接查看生成时间、使用的模型和生成参数，方便核对图片来源。

## What Changes

- 单选图片时，在顶部工具栏删除按钮右侧增加信息图标，悬停提示“查看图片详情”。
- 点击图标打开只读详情面板，展示生成时间（任务创建时间）、完成时间（有记录时）、模型、提示词、生成参数和图片尺寸。
- 优先使用图片绑定的生成任务 ID 查询原任务；没有绑定时复用已有图片结果 URL 查询逻辑。
- 参数仅展示生成配置，不展示凭据、认证信息或完整内部任务对象。
- 上传图片、历史记录不存在或字段缺失时明确显示“未记录”；读取失败时显示错误并允许重试。
- 关闭面板后保留图片选择；多选和非图片元素不显示该入口。

## Impact

- Affected specs: image-generation
- Affected code: 图片 popup-toolbar、独立图片详情组件、现有任务查询服务。
- 不调用模型、不产生生成费用、不改变图片或已有再次生成行为。
- 本次使用已有记录，不增加持久化字段或追补历史元数据。任务删除后无法恢复未保存的生成信息。
- 验证范围：组件逻辑、任务匹配与缺失/失败路径、类型及受影响检查；按项目要求不默认进行页面测试。
