# AI 任务栏单图仅作参考模式测试清单

**创建日期**：2026-08-05

**测试范围**：验证关闭任务栏跟随后，当前图片继续作为参考图但不覆盖原图，并验证按图片永久生效的仅作参考模式。

**关联交接文档**：[2026-08-05-AI 任务栏单图仅作参考模式交接文档](../../docs/2026-08-05-AI任务栏单图仅作参考模式-交接文档.md)

## 前置条件

1. 画布中准备图片 A、图片 B，二者均可触发单图任务栏跟随。
2. 使用支持保存和刷新同一白板的 OpenTu 网页环境。
3. 如执行真实生成，需配置可用的图片模型和供应商。
4. 分别覆盖桌面端和 `390 × 844` 移动端。
5. 测试记录不得包含 API Key、完整请求头或其他鉴权信息。

## 场景 1：入口与菜单

1. 单选图片 A，使任务栏进入图片跟随状态。
2. 检查任务栏右上方的 `X` 和下拉按钮。
3. 打开下拉菜单。

**预期结果**：

- [ ] `X` 可直接执行“本次只作参考图”。
- [ ] 菜单完整显示“本次只作参考图”和“对此图始终只作参考图”。
- [ ] 两个按钮均可通过键盘聚焦，并具有明确的 `aria-label`。
- [ ] 菜单不遮挡输入、模型、参数或发送按钮。

## 场景 2：本次只作参考图

1. 保持图片 A 为当前跟随目标。
2. 记录提示词、模型、尺寸、数量、手动参考图和知识库上下文。
3. 点击 `X`。
4. 平移、缩放画布，并移动指针。

**预期结果**：

- [ ] 任务栏回到底部，不再跟随图片 A。
- [ ] 图片 A 保持选中，并继续显示为“参考图”缩略图。
- [ ] 生成上下文与操作前一致。
- [ ] 平移、缩放或指针事件不会重新绑定图片 A。
- [ ] 参考图缩略图不会重复添加。
- [ ] 打开对话抽屉后图片 A 仍保持选择，并在抽屉中显示为参考图。

## 场景 3：临时模式恢复默认跟随

1. 完成场景 2 后点击画布空白处，取消选择图片 A。
2. 再次单选图片 A。

**预期结果**：

- [ ] 取消选择后，任务栏移除图片 A 的临时参考缩略图。
- [ ] 重新选择图片 A 后，任务栏恢复默认跟随。
- [ ] 后续未关闭的单图生成仍可按原有逻辑原位替换。

## 场景 4：对此图始终只作参考图

1. 单选图片 A，使任务栏进入跟随状态。
2. 打开下拉菜单，选择“对此图始终只作参考图”。
3. 保存并刷新当前白板。
4. 刷新后重新单选图片 A。

**预期结果**：

- [ ] 选择永久模式后，任务栏立即回到底部。
- [ ] 图片 A 保持选中，并继续显示为“参考图”缩略图。
- [ ] 图片 A 保存轻量字段 `aiTaskbarReferenceOnly: true`。
- [ ] 刷新后重新选择图片 A，任务栏仍不跟随，图片 A 仍作为参考图。
- [ ] 不新增图片副本、Base64 持久化或全局图片 ID 列表。

## 场景 5：永久模式按图片隔离

1. 图片 A 已启用永久仅作参考模式。
2. 单选未启用该模式的图片 B。
3. 再次切换选择图片 A。
4. 同时多选图片 A 和图片 B。

**预期结果**：

- [ ] 图片 B 继续触发默认任务栏跟随。
- [ ] 图片 A 再次被选择时仍只作参考图。
- [ ] 图片 A 的设置不会写入图片 B。
- [ ] 多选时不显示仅针对单图的永久模式入口。

## 场景 6：仅作参考模式的生成语义

临时模式和永久模式分别执行一次：

1. 进入对应的仅作参考模式。
2. 添加一张手动参考图。
3. 提交图片生成并等待任务完成。
4. 检查请求参数、原图片与生成结果。

**预期结果**：

- [ ] 当前点击图片位于 `referenceImages[0]`。
- [ ] 手动参考图继续保留，并排在当前图片之后。
- [ ] 原图片内容、元素 ID、位置和尺寸保持不变。
- [ ] 生成结果作为独立新图片插入画布。
- [ ] 请求不包含 `replaceElementId`、`targetElementId`、`anchorId`、`sourceTaskId` 或 `sourcePrompt`。

## 场景 7：布局与稳定性

1. 在桌面端和 `390 × 844` 移动端分别进入跟随状态并打开菜单。
2. 连续切换不同图片，交替执行临时和永久模式。
3. 观察任务栏尺寸、页面滚动和控制台。

**预期结果**：

- [ ] 菜单两项完整可见并可点击。
- [ ] 提示、关闭按钮和下拉按钮不裁切、不重叠。
- [ ] 页面无横向溢出，任务栏控件不发生异常位移。
- [ ] 控制台无错误，连续操作不重复添加参考图。
- [ ] 不出现明显内存持续增长。

## 通过标准

1. 临时和永久模式都保留当前图片作为第一参考图，同时解除跟随和原图覆盖。
2. 临时模式在选择变化后恢复默认跟随；永久模式刷新后仍按图片生效。
3. 永久模式不影响其他图片。
4. 仅作参考模式不携带任何目标替换字段，生成结果为独立新图。
5. 自动化回归全部通过，人工测试中的待测项在发布前完成且无阻断问题。
