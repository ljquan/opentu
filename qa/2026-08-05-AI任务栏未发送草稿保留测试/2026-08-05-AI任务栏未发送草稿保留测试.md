# AI 任务栏未发送草稿保留测试清单

**创建日期**：2026-08-05

**测试范围**：仅验证 AI 任务栏未发送草稿在普通误触和绑定图片切换时保持完整；成功发送、显式清理及现有画布选择行为保持不变。

**关联交接文档**：[2026-08-05-AI 任务栏未发送草稿保留-交接文档](../../docs/2026-08-05-AI任务栏未发送草稿保留-交接文档.md)

## 前置条件

1. 使用包含本修复的 OpenTu 网页环境并打开一个可编辑白板。
2. 配置可用的生成模型，准备至少两张可触发任务栏绑定的画布图片。
3. 准备一份可上传的参考内容和一条可选择的知识库引用。
4. 测试过程中不记录 API Key、完整请求头或其他鉴权信息。

## 场景 1：提示词在误触后保留

1. 在 AI 任务栏输入包含换行、中英文、标点和空格的提示词，但不要发送。
2. 依次点击画布空白、左侧工具、顶部控件和非输入区域。
3. 每次操作后重新聚焦 AI 任务栏。

**预期结果**：

- [ ] 提示词全文与输入前一致，换行、空格和光标前后的文本均未丢失。
- [ ] 普通失焦不会把提示词替换成绑定图片的历史提示词。
- [ ] 任务栏重新聚焦后可以继续编辑并正常发送。

## 场景 2：上传内容在误触后保留

1. 添加一份或多份任务栏支持的上传内容，不发送。
2. 点击画布空白和其他控件，再返回任务栏。
3. 打开参数、模型、数量等任务栏控件后关闭。

**预期结果**：

- [ ] 上传内容的数量、顺序、名称和预览保持不变。
- [ ] 误触不会把上传内容转为当前画布选择，也不会创建重复副本。
- [ ] 用户主动删除某项上传内容时，只删除该项，其余草稿仍保留。

## 场景 3：知识引用在误触后保留

1. 选择至少一条知识引用，并输入提示词，不发送。
2. 点击画布空白、其他控件，再回到任务栏。
3. 打开并关闭知识选择器，检查已选内容。

**预期结果**：

- [ ] 已选知识引用的数量、顺序和标识保持不变。
- [ ] 提示词、上传内容与知识引用可同时完整保留。
- [ ] 用户主动移除知识引用时，只移除所选项，不影响其他草稿内容。

## 场景 4：切换绑定图片保留草稿

1. 输入提示词并添加上传内容、知识引用，不发送。
2. 单选图片 A，使任务栏进入图片绑定状态。
3. 点击图片 B，确认任务栏切换到图片 B；再点击画布空白取消选择。

**预期结果**：

- [ ] 提示词、上传内容和知识引用在每次绑定变化后仍完整保留。
- [ ] 绑定目标可从图片 A 正常切换到图片 B，取消选择后按原有规则解除或更新。
- [ ] 当前画布选择内容按选择变化更新，不被误保存为用户上传内容。
- [ ] 绑定图片自带的提示建议不覆盖用户已经输入的提示词。

## 场景 5：成功发送与失败边界

1. 在未绑定图片时，准备包含提示词、上传内容和知识引用的有效草稿并发送。
2. 确认任务成功提交后检查任务栏。
3. 在绑定图片模式发送一次，确认继续沿用原有连续编辑行为。
4. 重新准备草稿，制造可恢复的提交失败并再次检查任务栏。

**预期结果**：

- [ ] 未绑定图片时，成功提交后按既有逻辑清空本次提示词、上传内容和知识引用。
- [ ] 绑定图片模式的提交后状态与修复前一致，不因本次草稿修复改变。
- [ ] 只创建一次对应任务，不因失焦或重新聚焦重复提交。
- [ ] 提交失败时保留未发送草稿，用户可修正后重试。

## 场景 6：显式清理与覆盖

1. 分别主动清空提示词、删除上传内容和移除知识引用。
2. 再次准备完整草稿，并触发已有的外部内容回填。
3. 在覆盖确认中分别选择取消和确认。

**预期结果**：

- [ ] 主动清理只影响用户明确操作的内容。
- [ ] 取消覆盖时完整保留原草稿。
- [ ] 确认覆盖时按回填内容更新草稿，既有确认流程正常。

## 场景 7：刷新与回归边界

1. 准备未发送草稿后刷新页面。
2. 检查模型、生成类型、参数和数量的既有偏好行为。
3. 验证图片跟随、解除跟随、单图替换和多图生成的既有流程。

**预期结果**：

- [ ] 本次不承诺刷新后恢复未发送草稿，且不会新增草稿恢复提示或服务端记录。
- [ ] 模型、生成类型、参数和数量仍遵循原有偏好规则。
- [ ] 图片绑定与生成流程无行为回归。
- [ ] 连续失焦和切换绑定目标不产生重复上传、重复知识引用或明显内存增长。
