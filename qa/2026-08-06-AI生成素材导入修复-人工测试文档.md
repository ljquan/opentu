## 验收目标

1. 新生成图片只有远程 URL、没有本地 Blob 时，仍可从素材库进入 AI 生图参考图表单；
2. 同一素材可进入 AI 视频的首帧、尾帧或参考图表单；
3. 虚拟缓存丢失、空 Blob 和非图片内容继续失败，不用无条件兜底隐藏错误；
4. Tuzi GPT 图片 JSON 请求可使用远程参考图 URL，其他适配器语义不变；
5. LAN 无 Cache API 时，缓存状态反映真实 Blob 是否存在。

## 范围边界

- 本次验收重点是“素材库选择并加载到表单”，不是生成质量或画布插入。
- 不使用缩略图替代原图。
- 不要求外部 CDN 的 CORS 错误消失。
- 真实供应商生成会消耗额度，本轮未执行，单独列为发布前待测项。

## 前置条件

1. 使用包含本修复的 OpenTu 页面；
2. 素材库中至少有一张当天新生成、仍可由 `<img>` 展示的远程图片；
3. 该图片在 `media-blobs` 中没有 Blob 实体；
4. 准备一个支持参考图的图片模型和视频模型；
5. 测试记录不得包含完整签名 URL、API Key、Cookie 或鉴权头。
