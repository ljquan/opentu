# AI 生图图片描述粘贴参考图测试清单

**创建日期**：2026-08-06

**测试范围**：仅验证 AI 生图图片描述区域粘贴图片成为参考图，以及文本粘贴和作用域隔离

**关联交接文档**：[2026-08-06-AI 生图图片描述粘贴参考图-交接文档](../docs/2026-08-06-AI生图图片描述粘贴参考图-交接文档.md)

## 前置条件

1. 使用包含本功能的 OpenTu 网页环境。
2. 打开“AI 图片生成”弹窗并停留在单图生成页。
3. 准备一张 PNG、一张 JPEG、一段纯文本和一个非图片文件。
4. 大图场景另准备 10MB 至 25MB 图片及超过 25MB 的图片。
5. 提交生成场景需要配置支持参考图的可用图片模型；测试记录不得包含 API Key。

## 测试边界

本清单只验证图片描述区域的参考图粘贴入口，不测试模型生成质量、供应商计费、历史任务修复、部署流程或其他弹窗的剪贴板行为。

## 场景 1：图片描述框粘贴单张图片

1. 点击“图片描述”文本框，确认光标位于文本框内。
2. 从剪贴板粘贴一张 PNG 图片。
3. 使用 JPEG 图片重复测试。

**预期结果**：

- [x] 图片粘贴事件被接管，不在描述文本中产生乱码或文件路径。
- [x] “参考图片（可选）”区域新增 1 张图片预览。
- [x] 粘贴后焦点仍位于图片描述文本框。
- [x] 当前图片描述内容不被修改或清空。
- [ ] JPEG 图片与已验证的 PNG 图片行为一致。

## 场景 2：图片描述框粘贴纯文本

1. 点击“图片描述”文本框。
2. 粘贴一段普通文本。

**预期结果**：

- [x] 纯文本粘贴不被参考图组件阻止。
- [ ] 文本按浏览器原行为进入图片描述。
- [x] 参考图列表不新增图片。

## 场景 3：图片描述区域外输入框粘贴图片

1. 让“图片描述”区域外、但仍在 AI 生图表单内的其他输入框获得焦点。
2. 粘贴一张图片。

**预期结果**：

- [x] AI 生图参考图组件不接管该粘贴事件。
- [x] AI 生图的参考图列表保持不变。
- [ ] 其他输入区域保持自身原有粘贴行为。

## 场景 4：多图和数量上限

1. 一次粘贴多张图片，检查预览顺序。
2. 连续粘贴，直到参考图总数达到 10 张。
3. 再次粘贴一张图片。

**预期结果**：

- [ ] 多张图片按剪贴板顺序追加，不覆盖已有参考图。
- [ ] 参考图总数不超过 10 张。
- [ ] 超出上限时显示原有数量提示，不新增无效预览。

## 场景 5：文件类型和大小限制

1. 尝试粘贴非图片文件。
2. 粘贴一张超过 25MB 的图片。
3. 粘贴一张 10MB 至 25MB 的图片。

**预期结果**：

- [ ] 非图片文件不进入参考图列表。
- [ ] 超过 25MB 的图片显示原有大小限制提示，不新增预览。
- [ ] 10MB 至 25MB 图片进入原有压缩流程，完成后可正常预览。
- [ ] 压缩失败时显示可读错误，已有参考图不受影响。

## 场景 6：已有参考图与删除操作

1. 先通过本地上传或素材库添加一张参考图。
2. 在图片描述框粘贴另一张图片。
3. 分别删除原参考图和粘贴参考图。

**预期结果**：

- [ ] 粘贴图片追加到已有参考图之后，不覆盖原图。
- [ ] 两种来源的参考图均可独立删除。
- [ ] 删除一张图片不会改变其他图片的顺序、预览或名称。

## 场景 7：携带粘贴参考图提交生成

1. 粘贴一张参考图并填写图片描述。
2. 选择支持参考图的图片模型并提交生成。
3. 检查任务参数和生成结果。

**预期结果**：

- [ ] 生成任务携带粘贴得到的参考图。
- [ ] 图片描述按用户输入提交，不被参考图内容改写。
- [ ] 任务创建、队列状态和结果展示沿用原有行为。
- [ ] 请求和日志不泄露 API Key 或额外剪贴板内容。

## 场景 8：禁用、关闭和重复打开

1. 在图片任务生成期间尝试粘贴图片。
2. 关闭 AI 图片生成弹窗后，在其他输入区域粘贴图片。
3. 重复打开、关闭弹窗并再次粘贴。

**预期结果**：

- [ ] 生成期间组件禁用时不新增参考图。
- [ ] 弹窗关闭后不再接管其他区域的粘贴事件。
- [ ] 重复打开不会造成一次粘贴添加多份图片。
- [ ] Console 不出现卸载后状态更新、重复监听或未处理异常。

## 场景 9：连续操作与内存边界

1. 连续粘贴、删除不同大小的图片。
2. 观察页面响应、浏览器内存和素材库结果。
3. 完成后关闭弹窗并等待一段时间。

**预期结果**：

- [ ] 连续操作不出现明显卡顿或持续增长的内存占用。
- [ ] 每次有效粘贴只新增对应图片，不发生旧异步结果覆盖新列表。
- [ ] 关闭弹窗后不再保留重复事件监听或继续更新已卸载组件。

## 通过标准

以下条件全部满足才可判定人工验收通过：

1. 图片描述框粘贴有效图片时只新增对应参考图，描述内容保持不变。
2. 纯文本和作用域外粘贴不被参考图逻辑误拦截。
3. 多图、大小限制、压缩、删除和最大数量继续复用原有规则。
4. 生成任务能携带粘贴参考图，且请求结构和其他参考图入口行为不变。
5. 禁用、关闭、重复打开和连续操作不产生重复监听、异常或持续内存增长。
