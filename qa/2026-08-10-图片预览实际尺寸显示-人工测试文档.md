# 图片预览实际尺寸显示测试清单

**创建日期**：2026-08-10

**测试范围**：验证统一图片预览显示任务结果实际像素尺寸，并确保任务栏预览、画布插入预览、异常数据及非图片媒体保持兼容

**关联变更**：`openspec/changes/add-image-preview-actual-dimensions`

**关联交接文档**：[2026-08-10-图片预览实际尺寸显示-交接文档](../docs/2026-08-10-图片预览实际尺寸显示-交接文档.md)

## 结果标记

- **已执行 - 通过**：本次功能开发中已有可复核的浏览器或自动化证据。
- **已执行 - 失败**：已经复现且结果不符合预期，需要记录问题。
- **待人工**：尚未完成真实交互、浏览器或压力验证，不得视为通过。

## 前置条件

1. 使用包含本功能的 OpenTu 网页环境。
2. 准备至少一个已完成图片任务，其 `result.width=1023`、`result.height=1537`。
3. 另准备无尺寸、非法尺寸、上传图片、视频和存量画布图片样本。
4. 测试记录、截图和日志不得包含 API Key、访问令牌或完整鉴权信息。
5. 大量图片测试使用隔离项目或浏览器上下文，不清理用户真实任务和画布数据。

## 范围与数据边界

- 预览尺寸与任务栏共用完成图片任务的 `result.width`、`result.height`。
- 仅接受正的安全整数，不使用请求比例、请求预设尺寸、图片自然尺寸或画布几何尺寸兜底。
- 任务列表预览直接透传任务结果尺寸。
- 手动插入的生成图片在画布节点持久化 `generationTaskId`；画布预览依次查询内存任务和持久化完成任务。
- 画布目标图片缺少任务 ID，或任务 ID 查询无法取得有效尺寸时，允许按结果 URL 回查；素材库 URL 不回查生成任务。
- 不新增后端接口、数据实体、外部请求或权限能力。

不测试供应商生成质量、图片尺寸解析来源、历史任务数据迁移、计费、图片编辑功能或部署流程。

**预期结果**：

- [x] 任务卡显示 `1023×1537`，与任务结果一致。

**预期结果**：

1. 批量插入至少 20 张有任务关联的生成图片。

- [ ] 每个插入图片节点关联正确任务，视频不写入图片任务关联。
- [ ] 无明显长任务、界面冻结、数组复制导致的阶梯式内存增长或持续定时器。
- [ ] 相同任务 ID、相同 URL 和相同回查策略的来源在单次预览内复用查询结果。

**状态**：批量节点绑定、重复查询和更新算法已有自动化/静态覆盖；20 张以上真实性能测试待人工。

## 通过标准

以下条件全部满足后，才可判定完整人工验收通过：

1. 任务列表和画布两个入口均显示与任务栏一致的任务结果实际尺寸。
2. 缺失或非法尺寸、上传图片、素材库图片、视频和音频均不误显示图片任务尺寸。
3. 查询错误、快速关闭和快速切换不会阻止预览或写入陈旧数据。
4. 存量画布只对目标图片执行受控 URL 回查，失败时静默降级。
5. 大量图片场景无明显卡顿、重复查询和持续内存增长。
6. 支持浏览器和响应式布局中尺寸文案位置正确、控件可用。
7. 不新增网络、后端、数据实体或权限边界，不暴露敏感信息。
