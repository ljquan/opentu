# AI 任务栏跨媒体目标测试清单

> [!IMPORTANT]
> 本文件是图片、视频、文本和音频生成目标的唯一现行 QA。其他按日期保存的任务栏测试只记录当时的专项变更；行为冲突时以本文件和关联交接文档为准。

- **目的**：验证 AI 生成的图片、视频、文本和音频目标使用一致的虚化提示词与同类型替换语义，并验证图片、视频、文本共用的任务栏跟随和参考/上下文控件。

## 能力矩阵

| 目标类型 | 进入生成目标模式的条件                                 | 虚化提示词 | 位置跟随开关     | X 与下拉菜单         | 跟随态同类型提交 |
| -------- | ------------------------------------------------------ | ---------- | ---------------- | -------------------- | ---------------- |
| 图片     | 单选图片；生成图片可读取 prompt，普通图片允许空 prompt | 生成图片有 | 有               | 参考图模式           | 原位替换         |
| 视频     | 单选且有生成 prompt，或精确任务 ID 可恢复 prompt       | 有         | 有               | 参考视频模式         | 原位替换         |
| 文本     | 单选且有生成 prompt，或精确任务 ID 可恢复 prompt       | 有         | 有               | 文本上下文模式       | 原位替换         |
| 音频     | 单选且有生成 prompt，或精确任务 ID 可恢复 prompt       | 有         | 无，沿用目标定位 | 无，保持既有绑定交互 | 原位替换         |

普通手写文本、手动导入的视频或音频没有生成元数据时不进入生成目标模式。系统不得从文本正文、媒体 URL 或不相关任务历史推断 prompt。

## 跨媒体通用场景

### 场景 A：四类生成目标显示虚化提示词

分别单选带 `generationPrompt` 或 `aiPrompt` 的图片、视频、文本和音频元素，检查任务栏类型、textarea 的 `value` 和 placeholder。

**结果判断**：

- [ ] 任务栏切换为目标对应的 `image`、`video`、`text` 或 `audio` 类型。
- [ ] textarea 的真实 `value` 为空，目标 prompt 只显示为“按空格或回车复用提示词：...”虚化候选。
- [ ] 候选不自动写入草稿、任务、提示词历史或画板数据。
- [ ] 页面只显示一套 AI 任务栏。

### 场景 B：精确任务绑定恢复与普通内容排除

1. 分别准备只含 `generationTaskId`、元素本身没有 prompt 的视频、文本和音频生成结果。
2. 确认该任务 ID 对应的任务有 prompt，再单选元素。
3. 分别测试不存在的任务 ID、任务无 prompt，以及没有任何生成元数据的普通文本、视频和音频。

**结果判断**：

- [ ] 有效任务 ID 只点查对应任务，并显示该任务的 prompt 候选。
- [ ] 失效任务 ID 或空 prompt 不绑定生成目标，也不扫描其他任务猜测来源。
- [ ] 普通文本不把正文当 prompt，普通视频和音频不把 URL 当生成来源。
- [ ] 普通内容保持原有选中、移动、播放或编辑行为。

### 场景 C：候选采纳、取消与输入法

对四类目标分别执行以下操作：空输入按 Space、空输入按 Enter、直接输入首字符、操作其他任务栏控件、使用中文输入法组合输入，并测试带修饰键的 Enter。

**结果判断**：

- [ ] Space 或 Enter 只把候选写入输入框，本次按键不提交任务。
- [ ] 再次按 Enter 才按现有规则提交真实输入。
- [ ] 直接输入或操作其他控件会取消候选，不拼接目标 prompt。
- [ ] 同一目标内将输入删空后候选不会自行恢复；重新建立目标上下文后才可再次显示。
- [ ] 输入法 composing、Shift/Alt/Ctrl/Meta 组合键、菜单键盘操作不会误采纳或误提交。

### 场景 D：跨类型切换与草稿隔离

1. 依次选择 prompt 不同的图片 A、视频 B、文本 C 和音频 D。
2. 在每个目标中输入不同草稿，并为支持的模式添加附件或知识库上下文。
3. 快速切换目标，并让 A 的异步选区解析晚于 D 返回。

**结果判断**：

- [ ] 当前任务栏类型、候选、草稿和目标预览只属于最后选中的目标。
- [ ] 各目标草稿互不串用，上一目标的手动附件和知识库上下文不会泄漏到下一目标。
- [ ] 目标状态键包含媒体类型；旧异步结果不能覆盖新目标。
- [ ] 取消选择后回到未绑定草稿，不显示上一目标候选。

### 场景 E：图片、视频和文本的任务栏跟随开关

对图片、视频和文本目标分别关闭、重新开启“任务栏跟随”，并在关闭期间缩放、平移和移动目标。

**结果判断**：

- [ ] 开启时任务栏吸附目标附近；关闭时回到底部默认位置。
- [ ] 关闭后目标、草稿和上下文继续保留，提交生成新内容且不覆盖原目标。
- [ ] 跟随开启时提交任务，在结果插入前关闭永久跟随；原目标保持不变，结果独立插入。
- [ ] 在途关闭后刷新页面，恢复任务完成时仍独立插入，不重新覆盖原目标。
- [ ] PPT、图片弹窗或其他无任务栏来源标记的显式替换不受该开关影响。
- [ ] 重新开启无需重新选择目标，任务栏立即恢复吸附与同类型原位替换能力。
- [ ] 开关偏好只在同一浏览器 origin 内持久化；存储不可用时安全回退。
- [ ] 音频目标沿用既有目标定位，但不显示该开关、X 或下拉菜单，也不受位置开关状态误影响。

### 场景 F：X 与临时/永久参考模式

分别在图片、视频和文本跟随态检查 X、下拉菜单和中英文文案，再执行临时与永久选项。

**结果判断**：

- [ ] 图片显示“本次只作参考图 / 对此图始终只作参考图”。
- [ ] 视频显示“本次只作参考视频 / 对此视频始终只作参考视频”，不得出现“参考图”。
- [ ] 文本显示“本次只作上下文 / 对此文本始终只作上下文”。
- [ ] 点击 X 等同于对应类型的“本次”选项，任务栏回到底部且解除原位替换绑定。
- [ ] 图片进入 `referenceImages`，视频进入 `selection.videos`，文本正文进入 `selection.texts`；目标内容置于同类手动内容前且不重复。
- [ ] 临时模式在选择变化后恢复默认跟随；永久模式通过目标上的轻量标记在刷新后继续生效，并且按元素隔离。
- [ ] 参考/上下文模式提交时不携带 `replaceElementId`、`targetElementId`、`anchorId`、`sourceTaskId` 或 `sourcePrompt`。

### 场景 G：跟随态同类型原位替换

对图片、视频、文本和音频各提交一次与目标类型相同的单结果生成，并记录元素 ID、位置、尺寸和层级。另行切换为不同生成类型提交一次。

**结果判断**：

- [ ] 同类型跟随态生成创建新任务并原位更新当前元素，不新增同类型孤立结果。
- [ ] 元素 ID、位置和层级保持不变；可固定的媒体尺寸保持不变。
- [ ] 文本内容更新后允许按新正文自动调整尺寸，并重新计算任务栏位置。
- [ ] 新 prompt 和任务 ID 写回目标，且不保存媒体二进制或完整任务历史。
- [ ] 不同类型提交不替换当前目标，仍走该生成类型的普通结果插入流程。

### 场景 H：失败、删除与迟到结果

1. 对四类目标分别提交会失败的同类型任务。
2. 再次提交成功任务，并在完成前删除目标或切换到另一目标。
3. 制造旧请求晚于新请求返回。

**结果判断**：

- [ ] 失败不修改原元素，也不新增空白或孤立元素。
- [ ] 目标被删除后，完成结果不得重新创建或覆盖其他元素。
- [ ] 迟到结果不能覆盖当前目标、草稿、候选或新任务元数据。
- [ ] 选区高频刷新不扫描完整任务历史，不产生持续增长的监听器、定时器、Object URL 或大对象缓存。

### 场景 I：布局、可访问性与多语言

在桌面端和 `390 × 844` 视口，分别以中文、英文和深浅色主题检查图片、视频和文本的跟随控件。

**结果判断**：

- [ ] 开关、提示、X 和菜单不遮挡输入框、模型、参数或发送按钮。
- [ ] 长提示词不溢出，菜单完整位于视口内。
- [ ] 图标按钮可键盘聚焦，具有正确的 `aria-label` 和 tooltip。
- [ ] 所有类型文案与当前目标一致，尤其视频不得复用图片文案。

## 图片专项场景（保留）

### 图片场景 1：选中生成图片后任务栏吸附

1. 单选一张已生成图片。
2. 观察任务栏位置和输入内容。

**结果判断**:

- ✅ 任务栏移动到图片附近。
- ✅ 输入框真实值为空，原提示词以虚化候选显示。
- ✅ 页面没有出现第二套控制条。

### 图片场景 2：缩放和平移后继续跟随

1. 保持目标图片为单选状态。
2. 缩放、平移画布，并把图片移动到视口边缘。

**结果判断**:

- ✅ 任务栏继续跟随目标。
- ✅ 下方空间不足时显示在图片上方。
- ✅ 任务栏不超出视口左右边界。

### 图片场景 3：取消选择后恢复底部位置

1. 点击画布空白处。
2. 尝试多选或选择普通图形。

**结果判断**:

- ✅ 任务栏回到底部默认位置。
- ✅ 多选和普通图形不进入目标编辑模式。

### 图片场景 4：编辑提示词并原位替换

1. 记录目标图片的元素 ID、位置和宽高。
2. 修改提示词并提交。
3. 等待新任务成功。

**结果判断**:

- ✅ 创建新的生成任务，不复用旧任务重试。
- ✅ 原图片内容更新，不新增第二张图片。
- ✅ 元素 ID、位置和宽高保持不变。
- ✅ 图片 prompt、最新任务 ID 和 anchor ID 更新。

### 图片场景 5：失败时保留原图

1. 使用不可用模型或参数提交目标编辑。
2. 等待任务失败。

**结果判断**:

- ✅ 原图片内容、位置和尺寸不变。
- ✅ 任务栏显示失败状态。
- ✅ 修改参数后可以再次提交。

### 图片场景 6：生成期间删除目标

1. 提交目标编辑任务。
2. 在任务完成前删除目标图片。

**结果判断**:

- ✅ 结果处理提示目标不存在。
- ✅ 不新增孤立图片或空白节点。

### 图片场景 7：普通上传图片空上下文跟随

1. 先选中一张带提示词的生成图片。
2. 再单选没有生成 prompt 和任务绑定的普通上传图片。

**结果判断**:

- ✅ 不回填其他图片提示词。
- ✅ 不绑定无关任务或 anchor。
- ✅ 任务栏跟随当前图片并显示其缩略图。
- ✅ 输入框为空，普通图片原有选中、移动和缩放行为正常。

### 图片场景 8：批量图片只替换所选目标

1. 批量生成至少两张图片。
2. 只选中其中一张并修改提示词。

**结果判断**:

- ✅ 只有所选图片被替换。
- ✅ 其他图片内容、位置和元数据不变化。

### 图片场景 9：局域网本地图片缩略图一致

1. 分别通过文件选择、拖拽、粘贴和素材库导入图片。
2. 至少保留两张内容和尺寸明显不同的图片。
3. 依次单选两张图片，观察画布和任务栏缩略图。

**结果判断**:

- ✅ 两张图片都能正常显示，不出现破图或闪退。
- ✅ 四种导入入口使用相同的格式识别和稳定 URL 规则。
- ✅ 任务栏缩略图与当前选中图片内容一致。
- ✅ `/asset-library/...` 在无 Service Worker 或 Cache Storage 时仍能从 IndexedDB Blob 降级缓存解析。

### 图片场景 10：普通本地图片原位生成

1. 单选一张普通本地图片。
2. 在任务栏输入新提示词并提交图片生成。
3. 等待任务完成。

**结果判断**:

- ✅ 新任务绑定当前本地图片目标。
- ✅ 成功后原位更新图片，不新增孤立图片。
- ✅ 元素 ID、位置、宽高和层级保持不变。
- ✅ 新提示词、任务 ID 和 anchor ID 写入当前图片。

### 图片场景 11：切换目标后清除旧输入上下文

1. 选中图片 A，在任务栏输入提示词并添加手动参考图或知识库上下文。
2. 改为选中图片 B。

**结果判断**:

- ✅ 图片 B 没有生成提示词时，输入框恢复为空。
- ✅ 图片 A 的手动附件和知识库上下文不会留在图片 B。
- ✅ 任务栏只显示图片 B 的目标缩略图。

### 图片场景 12：同一元素换源后刷新缩略图

1. 保持同一图片元素 ID，通过原位替换更新其 URL、提示词或任务 ID。
2. 观察画布图片和任务栏缩略图。

**结果判断**:

- ✅ 元素 ID 不变时仍会刷新目标上下文。
- ✅ 缩略图、虚化提示词候选、任务 ID 和 anchor ID 与最新目标一致。
- ✅ 不需要取消选择后重新选择。

### 图片场景 13：快速切换不会回退旧图

1. 在图片 A 的本地 Blob 尚未解析完成时快速切换到图片 B。
2. 等待两次缓存读取都完成。

**结果判断**:

- ✅ 最终显示图片 B，不会被晚到的图片 A 覆盖。
- ✅ 旧重试定时器不会重新写回图片 A。
- ✅ 旧 Object URL 被释放，没有持续增长的 Blob URL 引用。

### 图片场景 14：刷新后本地图片可恢复

1. 导入本地图片并保存白板。
2. 刷新页面或重新打开同一白板。

**结果判断**:

- ✅ 图片仍显示正确内容和尺寸。
- ✅ 白板保存的是稳定 `/asset-library/...` URL，不是失效的 `blob:`。
- ✅ 再次选中后，任务栏缩略图仍与目标一致。

## 通过标准

1. 图片、视频、文本和音频生成目标都能显示自己的虚化提示词，Space/Enter 只采纳一次且不立即提交。
2. 普通非图片内容不被误判为生成目标，跨类型切换不会串用候选、草稿、附件或任务绑定。
3. 图片、视频和文本具有一致的位置跟随开关、X 和菜单，并显示与目标类型匹配的中英文文案；音频不出现这些控件。
4. 关闭任务栏跟随或进入临时/永久参考模式时保留目标内容，但解除原位替换；在途任务完成后也插入新结果而不覆盖原目标，重新开启后仅影响后续提交。
5. 四类目标的同类型单结果生成均按既有链路原位替换；失败、目标丢失或迟到结果不修改画布。
6. 图片原有的普通本地图、批量生成、局域网缩略图、缓存恢复和异步换源场景不回归。
7. 桌面端、窄屏、键盘操作、输入法、主题和多语言下无误提交、遮挡、越界或持续资源增长。
