# 图片生成实际尺寸展示测试清单

**创建日期**：2026-08-03

**测试范围**：仅验证图片生成结果的实际尺寸透传、展示、未知尺寸兜底和缩略图完整显示

**关联交接文档**：[2026-08-03-图片生成实际尺寸展示-交接文档](../docs/2026-08-03-图片生成实际尺寸展示-交接文档.md)

## 前置条件

1. 使用包含本功能的 OpenTu 网页环境。
2. 配置可用的 GPT Image 或 Tuzi GPT Image 供应商和图片模型。
3. 准备至少一个能返回 `1024×1536` 竖图的生成场景。
4. 批量场景需要允许每张图片返回不同尺寸。
5. 测试记录、截图和日志不得包含 API Key 或完整鉴权信息。

## 测试范围

- 上游 `width`、`height` 和 `size` 元数据解析。
- 上游没有尺寸字段时读取最终图片真实像素宽高。
- 任务结果宽高透传和持久化。
- 单图与批量任务的实际尺寸展示。
- “未知尺寸”兜底。
- 缩略图不裁剪、不拉伸和图片悬停不放大。

不测试历史任务数据修复、供应商计费、模型生成质量、图片编辑能力或部署流程。

## 场景 1：上游直接返回数字宽高

1. 使用会在单张图片结果中返回数字 `width`、`height` 的接口生成图片。
2. 检查上游结果宽高和任务列表尺寸文案。
3. 刷新页面后再次检查该任务。

**预期结果**：

- [ ] 任务列表显示与上游一致的 `宽×高`。
- [ ] 刷新后尺寸保持不变。
- [ ] 不显示请求比例或请求预设尺寸。

## 场景 2：字符串宽高和公共 size 兼容

分别使用以下响应形式完成图片任务：

- `width: "1024"`、`height: "1536"`。
- 单张图片结果包含 `size: "1024x1536"`。
- 响应公共字段包含 `size: "1024x1536"`。

**预期结果**：

- [ ] 三种响应均显示 `1024×1536`。
- [ ] 字符串会转换为有效正整数。
- [ ] `2x3` 等比例字符串不会被当作像素尺寸。

## 场景 3：上游 JSON 没有尺寸字段

1. 使用只返回图片 URL 或 `b64_json`、不返回宽高字段的 Tuzi/GPT Image 接口。
2. 生成一张实际像素为 `1024×1536` 的图片。
3. 等待任务完成并查看任务列表。

**预期结果**：

- [ ] 系统读取最终图片文件的真实像素宽高。
- [ ] 任务列表显示 `1024×1536`，不显示“未知尺寸”。
- [ ] 不使用请求参数补齐宽高。

## 场景 4：请求条件与实际结果不一致

1. 提交带有比例或预设尺寸的图片请求。
2. 让上游返回与请求预设不同的最终像素尺寸。
3. 对比请求参数、图片实际属性和任务列表文案。

**预期结果**：

- [ ] 任务列表始终显示最终图片真实像素尺寸。
- [ ] 不显示 `1:1`、`2:3` 等比例文案。
- [ ] 不会把请求的 `1024×1024` 误显示为实际结果尺寸。

## 场景 5：批量图片尺寸不同

1. 创建至少 3 张图片的批量生成任务。
2. 让各图片返回不同实际尺寸，例如 `1024×1536`、`1536×1024`、`1024×1024`。
3. 检查每个批量子任务的尺寸。

**预期结果**：

- [ ] 每张图片显示自己的实际尺寸。
- [ ] 一个子任务的宽高不会覆盖其他图片。
- [ ] 批次序号、完成状态和图片链接仍正常显示。

## 场景 6：无有效尺寸时显示未知

分别模拟以下情况：

- 上游返回 `width: 0`、缺少 `height` 或非法 `size`。
- 最终图片 URL 不可访问或图片无法解码。
- 尺寸读取超过有界等待时间。

**预期结果**：

- [ ] 任务完成后显示“未知尺寸”。
- [ ] 不回退请求比例、请求宽高或缩略图容器尺寸。
- [ ] 尺寸解析失败不会修改图片 URL 或让已成功任务变为失败。

## 场景 7：缩略图完整显示

1. 分别生成竖图、横图和方图。
2. 检查任务列表缩略图的主体边缘。
3. 将鼠标移入、移出图片缩略图。

**预期结果**：

- [ ] 图片保持原比例完整显示，没有裁剪或拉伸。
- [ ] 图片悬停时不放大，边缘不会因缩放被裁掉。
- [ ] 视频缩略图原有悬停效果不受影响。

## 场景 8：取消和慢图片加载

1. 在最终图片尺寸读取期间取消任务或中断请求。
2. 使用加载较慢的最终图片重复测试。

**预期结果**：

- [ ] 取消信号可结束尺寸等待，不产生长期挂起。
- [ ] 单张图片解析不会阻塞其他批量任务。
- [ ] 不出现持续定时器、重复图片读取或明显内存持续增长。

## 场景 9：历史任务边界

1. 打开本功能上线前已完成、但没有持久化结果宽高的任务。
2. 对比新生成任务。

**预期结果**：

- [ ] 历史任务不执行批量回填或数据迁移。
- [ ] 无宽高的历史任务允许显示“未知尺寸”。
- [ ] 新任务按新规则显示实际尺寸。

## 通过标准

以下条件全部满足才可判定人工验收通过：

1. 新图片任务显示上游最终图片的真实 `宽×高`。
2. 上游无尺寸字段时仍能从最终图片取得实际像素尺寸。
3. 请求参数和比例不会覆盖实际结果尺寸。
4. 批量图片分别显示自己的尺寸。
5. 无法取得尺寸时只显示“未知尺寸”，不影响任务成功结果。
6. 缩略图完整显示且图片悬停不裁剪。
