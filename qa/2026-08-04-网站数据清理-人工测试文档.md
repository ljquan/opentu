# 网站数据清理测试清单

**创建日期**：2026-08-04  
**测试范围**：仅验证桌面端网站数据清理入口、两种清理模式、保留边界、强确认、失败处理和页面刷新  
**关联交接文档**：[2026-08-04-网站数据清理-交接文档](../docs/2026-08-04-网站数据清理-交接文档.md)

## 前置条件

1. 使用包含本功能的 OpenTu 网页环境和桌面浏览器。
2. 测试前备份需要保留的本地画板、素材或记录；“清除全部本地数据”不可恢复。
3. 准备可识别的图片/媒体缓存、生成任务、工作流、聊天、素材、知识库和本地画板测试数据。
4. 设置可识别的主题、语言、模型配置、提示词预设及登录 Cookie，用于验证保留边界。
5. 风险场景需额外准备活动任务、运行中工作流或未同步本地变更。
6. Service Worker 场景应在已注册且已控制当前页面的正式 PWA 环境执行。
7. 测试截图和日志不得包含 Cookie、令牌、API Key 或完整鉴权信息。
8. 验证“本地数据保持清空”时应暂停远端自动同步或使用无远端数据的测试账号；本功能不删除远端数据，已同步内容在刷新后重新拉取属于预期行为。

## 测试范围

- 桌面端左侧工具栏入口和位置。
- “仅清除缓存”与“清除全部本地数据”两种模式。
- 活动任务、运行中工作流和未同步变更风险提示。
- Cookie、登录状态、Service Worker 和用户偏好保留。
- 成功刷新、失败不刷新和重复提交防护。
- IndexedDB、LocalStorage、Cache Storage 与页面内存的清理边界。

不测试移动端或触屏布局适配、服务端数据删除、数据导出、自动同步、回收站或部署流程。

## 场景 1：桌面入口与位置

1. 使用桌面浏览器打开画布页面。
2. 检查左侧工具栏底部按钮顺序。
3. 悬停并点击最下方垃圾桶按钮。

**预期结果**：

- [ ] 任务队列下方新增一个独立垃圾桶按钮。
- [ ] 垃圾桶是左侧工具栏最下方按钮。
- [ ] 悬停文案和无障碍名称均为“清理网站数据”。
- [ ] 本功能没有新增任何无关工具栏入口。
- [ ] 点击后打开“清理网站数据”弹窗。

## 场景 2：默认缓存模式

1. 打开清理弹窗。
2. 检查默认选项和说明文案。
3. 关闭弹窗后重新打开。

**预期结果**：

- [ ] 默认选择“仅清除缓存”。
- [ ] 确认按钮显示“清除缓存”且可直接点击。
- [ ] 文案明确不会删除生成记录或本地文件。
- [ ] 重新打开后恢复默认模式，不保留上次确认输入。

## 场景 3：仅清除缓存

1. 预先写入媒体元数据、媒体 Blob、图片缩略图、头像及图片/视频预览缓存。
2. 同时保留一条生成任务、一个本地画板、一条聊天记录和一个素材记录。
3. 记录主题、语言、模型配置和登录 Cookie。
4. 执行“清除缓存”，等待页面刷新。
5. 在浏览器存储面板复查数据。

**预期结果**：

- [ ] 统一媒体元数据和 Blob 缓存被清空。
- [ ] 图片、缩略图、头像及预览缓存被清空。
- [ ] 生成任务、聊天、素材和本地画板仍然存在。
- [ ] 主题、语言、模型配置、Cookie 和登录状态保持不变。
- [ ] 当前页面只刷新一次。

## 场景 4：完整清理强确认

1. 切换到“清除全部本地数据”。
2. 分别输入空值、错误文字、前后带空格的文字和“确认清除”。
3. 检查确认按钮状态。

**预期结果**：

- [ ] 弹窗显示不可恢复警告。
- [ ] 未输入完全一致的“确认清除”时，确认按钮不可用。
- [ ] 只有输入完全一致的“确认清除”后，按钮才可用。
- [ ] 即使没有活动任务或未同步数据，完整清理仍要求强确认。

## 场景 5：清除全部本地数据

1. 准备任务、工作流、聊天、素材、角色、知识库、音频播放列表、创作记录和本地画板。
2. 准备主题、语言、模型配置、接口设置、提示词预设、隐藏记录、编辑覆盖值及登录 Cookie。
3. 选择“清除全部本地数据”，输入“确认清除”并执行。
4. 页面刷新后检查各类浏览器存储与界面状态。

**预期结果**：

- [ ] 任务、工作流及其历史记录被清空。
- [ ] 聊天、素材、角色、知识库、创作记录和本地画板被清空。
- [ ] 图片、媒体、缩略图、头像和预览缓存被清空。
- [ ] 主题、语言、模型、接口及其他用户偏好保持不变。
- [ ] 提示词预设、隐藏记录和用户编辑覆盖值保持不变。
- [ ] Cookie 和登录状态保持不变。
- [ ] 不产生任何服务端数据删除请求。

## 场景 6：活动任务与未同步内容

分别准备以下状态后打开完整清理模式：

- 一个或多个活动任务。
- 一个或多个运行中工作流。
- 未同步到远端的本地变更。
- 三种状态同时存在。

**预期结果**：

- [ ] 弹窗显示检测到的活动任务数量。
- [ ] 弹窗显示检测到的运行中工作流数量。
- [ ] 存在未同步变更时明确提示。
- [ ] 输入“确认清除”后允许继续，不要求同步或导出。
- [ ] 清理会中止活动任务和运行中工作流。
- [ ] 页面刷新后，被中止内容不会迟到写回或重新出现。

## 场景 7：Service Worker 保留边界

1. 在已注册并控制页面的 PWA 环境生成图片、视频和缩略图缓存。
2. 记录当前 Service Worker 注册状态。
3. 分别执行缓存清理和完整清理。
4. 检查 Cache Storage、后续缓存命中和注册状态。

**预期结果**：

- [ ] 页面侧与 Service Worker 侧图片、视频内存缓存被清空。
- [ ] 图片与缩略图 Cache Storage 被删除。
- [ ] Service Worker 注册仍然存在，不触发注销。
- [ ] 清理后新请求可以重新建立缓存。

## 场景 8：失败处理与重试

1. 在开发环境分别模拟 IndexedDB、头像缓存或 Service Worker 清理失败。
2. 执行对应清理模式。
3. 关闭错误条件后重新执行。

**预期结果**：

- [ ] 失败时显示包含原因的错误提示。
- [ ] 失败时不刷新当前页面。
- [ ] 完整清理失败后恢复任务与工作流写入能力。
- [ ] 解除错误后可以重新发起清理。
- [ ] 不把部分成功错误显示为完整成功。

## 场景 9：配置同库与缺失数据库兼容

1. 在业务 store 和配置 store 共存的 IndexedDB 中写入测试数据。
2. 保证另一项待清理数据库尚未创建。
3. 执行完整清理。

**预期结果**：

- [ ] 只清空白名单中的业务 store，配置 store 保持不变。
- [ ] 不删除整个 IndexedDB 数据库。
- [ ] 不因检查缺失数据库而创建新的空数据库。
- [ ] 其他不在白名单内的本地配置不受影响。

## 场景 10：重复点击与大数据量

1. 在存储中准备较多媒体缓存和业务记录。
2. 连续多次点击确认按钮。
3. 观察页面响应、内存和清理调用次数。

**预期结果**：

- [ ] 同一次清理期间只执行一个清理流程。
- [ ] 不出现重复刷新、重复错误提示或并发数据库清理。
- [ ] 不把完整媒体文件批量读取到 JavaScript 内存。
- [ ] 清理结束后没有持续增长的内存、计时器或后台写回。

## 通过标准

以下条件全部满足才可判定最终人工验收通过：

1. 桌面端最下方只显示本功能新增的“清理网站数据”入口。
2. 缓存模式只删除缓存，任务、记录、本地文件和个人配置保持不变。
3. 完整模式必须强确认，并清除白名单内全部本地业务数据。
4. 活动任务和未同步内容可在明确警告后由用户确认放弃，且不会迟到写回。
5. Cookie、登录状态、Service Worker 注册、主题、语言和模型配置始终保留。
6. 成功后只刷新当前页面一次；失败时不刷新且可重试。
7. 正式 PWA 环境中的 Service Worker 清理与保留边界验证通过。
