## 8. Seedance 官方请求验收

### 8.1 最小请求

提交文本、5 秒、720p、16:9 的任务。

- [ ] 请求方法为 `POST /v1/videos`。
- [ ] `Content-Type` 为 `application/json`。
- [ ] `model` 使用选中的 `doubao-seedance-2-0-*` ID。
- [ ] `duration` 为数字，`generate_audio` 和 `watermark` 为布尔值。
- [ ] 返回 2xx 和可轮询的任务 ID。

### 8.2 参数边界

分别提交以下组合：

1. 4 秒、480p、16:9、`seed: 0`、`camera_fixed: false`。
2. 12 秒、1080p、adaptive、生成音频关闭、水印开启。

- [ ] OpenTu JSON 保留所选值和正确类型。
- [ ] `seed: 0` 和 `camera_fixed: false` 不丢失。

### 8.3 非法参数

尝试 3 秒、13 秒、小数时长、4K、832 宽度、未知比例和字符串布尔值。

- [ ] OpenTu 可识别的非法值在提交前被拦截。
- [ ] OpenTu 拦截后不创建任务，也不进入轮询。

## 9. 参考媒体与异步状态验收

### 9.1 参考图片、视频和音频

- [ ] 参考图片使用 `image_url` 与 `role: reference_image`。
- [ ] 公网参考视频使用 `video_url` 与 `role: reference_video`。
- [ ] 私网、本机、Blob、Data URL 参考视频被拒绝。
- [ ] 公网音频 URL、合法音频 Data URL 和素材 ID 使用 `audio_url` 与 `role: reference_audio`。
- [ ] 音频 Data URL 非法 MIME、非法 Base64 或超过 16 MiB 时被拒绝。
- [ ] 移除参考音频后，请求不再包含 `audio_url`。
- [ ] 编辑或重试任务时，参考媒体和参数不会丢失。

### 9.2 轮询、完成与失败

- [ ] 使用 `GET /v1/videos/{taskId}` 轮询同一个任务。
- [ ] `queued`、`processing` 会更新任务队列进度。
- [ ] `completed/succeeded` 优先读取内联 URL，无 URL 时读取内容接口。
- [ ] 最终 MP4 可下载并插入画布。
- [ ] `failed/error` 立即结束并展示脱敏后的上游错误。
- [ ] 网络错误、408、425、429 和 5xx 使用有界退避。
- [ ] 普通 400、401、403、404 不重试、不重复创建任务。
- [ ] 取消任务后停止轮询。
