# AI 任务栏画布联想引用与平滑连线测试清单

**创建日期**：2026-08-12

**测试范围**：验证联想永久开关、任意位置 `@` 拾取、多类型稳定编号、多来源完整提交、任务及结果连线、开放视觉引用数量、曲线迁移、异常恢复、跨画板和性能边界。

**关联交接文档**：[2026-08-12-AI 任务栏画布联想引用与平滑连线交接文档](../../docs/2026-08-12-AI任务栏画布联想引用与平滑连线-交接文档.md)

## 前置条件

1. 当前画板准备至少三张图片、一个文本、一个卡片或画框，可选准备视频和音频。
2. 任务栏书籍按钮旁可看到联想按钮。
3. 准备一个可创建任务节点的视频或图片模型；真实生成会消耗额度。
4. 如验证供应商超推荐数量行为，应保存供应商返回的错误摘要，不记录 API Key、Authorization 或完整请求头。
5. 分别覆盖桌面端与窄屏视口，测试前备份重要画板。

## 场景 1：永久开关

1. 确认联想按钮初始为关闭。
2. 点击按钮开启联想。
3. 刷新页面并重新打开同一画板。
4. 再次点击关闭并刷新。

**预期结果**：

- [ ] 按钮位于书籍按钮旁，不遮挡其他任务栏控件。
- [ ] 开启时提示为“关闭联想”，并具有按下状态。
- [ ] 开启状态刷新后保持。
- [ ] 关闭状态刷新后保持。
- [ ] 存储不可用时页面仍可运行，不出现白屏或未捕获异常。

## 场景 2：新输入 `@` 与取消拾取

1. 开启联想，在正文开头逐键输入 `@`。
2. 按 `Escape` 取消。
3. 在中文正文中间逐键输入新的 `@`。
4. 点击画布空白，再次触发并切换不同画布工具测试。

**预期结果**：

- [ ] 新输入 `@` 后画布进入拾取模式。
- [ ] `@` 前不要求空格，可位于正文中间。
- [ ] `Escape` 取消后保留原文字并恢复输入焦点。
- [ ] 取消或完成拾取后恢复原画布工具。
- [ ] 点击空白不创建引用，不误绘图形。
- [ ] 粘贴或拖入包含 `@图片1` 的文本不进入拾取，也不获得对象身份。

## 场景 3：连续多类型拾取与稳定编号

输入：

```text
首帧用@，尾帧用@，字幕用@，参考画面用@
```

依次拾取图片 A、图片 B、文本 C、卡片 D。

**预期结果**：

- [ ] 显示 `@图片1`、`@图片2`、`@文本1`、`@卡片1`。
- [ ] 不出现两个不同来源都叫 `@图片1`。
- [ ] 第二次拾取不会切换任务栏绑定草稿或清空第一次引用。
- [ ] 提示词正文、光标位置和标点保持正确。
- [ ] 同一来源再次拾取时提示重复，不添加第二份身份。
- [ ] 删除完整 token 后，对应引用身份移除，其他编号和身份不重写。

## 场景 4：所有引用立即连接任务节点

1. 连续引用图片 A、图片 B、文本 C 或卡片 D。
2. 提交视频任务。
3. 在任务状态变为“执行中”后立即检查画布，不等待供应商返回。
4. 分别覆盖成功、执行失败和供应商参数错误。

**预期结果**：

- [ ] 任务节点出现后，每个引用来源立即各有一条关系线。
- [ ] 建线不等待 Service Worker 或供应商异步响应。
- [ ] 不只连接最后一个引用。
- [ ] 执行失败或参数错误时，任务节点和全部来源线仍保留。
- [ ] 重复状态通知或重试不会产生重复线。

## 场景 5：视觉来源数量完全开放

1. 选择上传控件推荐最多两张参考图的视频模型。
2. 在提示词中引用三张图片，或两张图片加一个卡片/画框。
3. 提交任务并观察前置提示和任务节点。

**预期结果**：

- [ ] 不再出现“当前视频模型最多支持 2 个图片联想引用”。
- [ ] 三个视觉来源都进入提交快照，不截断卡片、画框或图形。
- [ ] 三个来源都连接任务节点。
- [ ] 若供应商不接受该数量，展示供应商真实错误，关系线仍保留。
- [ ] 上传控件自身的模型参数和普通手动附件行为不被改写。

## 场景 6：大型来源与输出预算

1. 引用包含大量子元素的画框或卡片。
2. 引用逻辑宽高或面积很大的图形组合。
3. 连续引用两个大型来源并提交。

**预期结果**：

- [ ] 不因来源元素数量、逻辑边长或逻辑面积拒绝。
- [ ] 完整逻辑边界被解析，不裁剪、不删除子元素。
- [ ] 多个来源串行转换，不同时展开多份输出。
- [ ] 输出图片遵守最长边和总像素预算。
- [ ] 原画布来源的位置、尺寸和内容保持不变。
- [ ] 页面无持续增长的明显内存占用或长时间失去响应。

## 场景 7：平滑曲线与自然汇聚

1. 将三个来源放在结果左侧的上、中、下位置。
2. 提交生成并等待结果位于右侧。
3. 再创建来源与目标横向重叠、目标位于下方的布局。

**预期结果**：

- [ ] 联想线为平滑曲线，无箭头。
- [ ] 线条为黑色 `2px`，清晰但不遮挡节点内容。
- [ ] 右向布局从来源右边连接到目标左边，并自然汇聚。
- [ ] 左向布局从来源左边连接到目标右边。
- [ ] 横向重叠时使用相向上下边，不出现明显 S 形绕线。
- [ ] 普通手绘直线、箭头线和业务节点样式完全不变。

## 场景 8：旧线迁移

1. 打开包含旧版联想直线的画板。
2. 刷新页面。
3. 移动或缩放任一来源和目标。

**预期结果**：

- [ ] 旧联想直线自动升级为当前平滑曲线。
- [ ] 颜色、宽度、无箭头和锁定状态恢复为托管样式。
- [ ] 迁移不新增撤销历史。
- [ ] 端点随元素移动更新。
- [ ] 关系元数据和工作流身份保持不变。

## 场景 9：最终结果迁线

1. 引用两个以上来源并提交任务。
2. 等待最终图片或视频插入画布。
3. 模拟或触发重复完成通知。

**预期结果**：

- [ ] 原来源到任务节点的关系线迁移到第一个稳定结果。
- [ ] 线条 ID 保持，未创建第二组关系线。
- [ ] 所有来源均迁移，不只迁移最后一个。
- [ ] 并发工作流只迁移各自 `workflowId` 对应的线。
- [ ] 重复完成通知保持幂等。

## 场景 10：删除与移动

1. 移动、缩放来源和目标。
2. 删除其中一个来源。
3. 在另一个任务中删除目标。

**预期结果**：

- [ ] 移动、缩放后端点更新到合适边缘。
- [ ] 删除来源只删除与该来源相关的关系线。
- [ ] 删除目标删除所有以该目标为端点的关系线。
- [ ] 未删除的业务元素和普通连线不受影响。

## 场景 11：错误输入与来源失效

1. 拾取来源后，在提交前删除该来源。
2. 拾取来源后切换到另一个画板再提交。
3. 引用无效几何、不可访问媒体 URL 或不受支持媒体类型。

**预期结果**：

- [ ] 已删除来源给出明确错误，输入和其他引用保留。
- [ ] 换板提交被阻止，不在错误画板插入任务或连线。
- [ ] 无效几何或媒体给出可恢复错误，不出现白屏。
- [ ] 不把纯文本 `@标签` 猜测为已删除来源。
- [ ] API Key、完整请求头和媒体二进制不会进入关系元数据或日志。

## 场景 12：跨画板与并发

1. 在画板 A 引用来源并提交。
2. 提交后立即切换到画板 B。
3. 在两个画板并发提交使用相同来源类型的任务。
4. 返回画板 A。

**预期结果**：

- [ ] 画板 A 的任务和关系线不会写入画板 B。
- [ ] 已接受任务保留轻量延迟建线意图。
- [ ] 返回来源画板后最多补线一次。
- [ ] 不同工作流通过 `workflowId` 隔离。
- [ ] 延迟意图不携带媒体二进制，超过上限时淘汰最旧记录。

## 场景 13：窄屏与可访问性

1. 在 `390 × 844` 视口开启和关闭联想。
2. 输入 `@`、取消、连续拾取并提交。
3. 使用键盘聚焦联想按钮。

**预期结果**：

- [ ] 联想按钮不与书籍、模型、参数和发送按钮重叠。
- [ ] 提示词 token 不遮挡正文或溢出任务栏。
- [ ] 按钮具有明确 `aria-label` 和按下状态。
- [ ] 页面无横向溢出，画布与任务栏可正常缩放、滚动。
