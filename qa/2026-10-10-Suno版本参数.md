# Suno v6 版本参数验证

## 效果与范围

- 版本菜单提供 `chirp-v6`（默认，均衡）、`chirp-v6-wild`（风格更奔放）、`chirp-v6-mini`（更快）。
- 音乐分析页、模型参数、Provider 自动推断和请求缺省版本统一为 `chirp-v6`；MCP 参数说明同步更新。
- 模型仍为 `suno_music`，提交使用 `POST /suno/submit/music`，轮询使用 `GET /suno/fetch/{taskId}`。
- 显式任务版本继续透传，上传续写后缀处理沿用现有逻辑；旧界面偏好按既有枚举校验恢复默认值。

## 环境与验证命令

隔离工作树，Node.js 26.8.1、Vitest 3.2.4，复用现有本地依赖。传输使用 mock，无真实供应商请求。

在 `packages/drawnix` 执行：

```sh
NODE_OPTIONS=--no-experimental-webstorage pnpm exec vitest run --config vitest.config.ts src/constants/__tests__/model-config.test.ts src/services/__tests__/provider-routing.test.ts src/services/__tests__/audio-api-service.test.ts --silent
```

在仓库根目录执行：

```sh
NODE_OPTIONS=--no-experimental-webstorage pnpm exec vitest run --config packages/drawnix/src/workflow-mode/web/vitest.config.ts tests/native-local-models.test.ts -t Suno --silent
pnpm exec tsc -p packages/drawnix/tsconfig.lib.json --noEmit
git diff --check
```
