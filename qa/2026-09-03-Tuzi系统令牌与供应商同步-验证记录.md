验证系统令牌和用户 ID 的本地保存、URL 参数解析、账户数据读取、日志分页、托管供应商同步、换新 Key，以及未连接时保留用户自定义供应商。

结果：7 个测试文件、38 个测试全部通过。

已覆盖：

- 连接和替换令牌后自动刷新当前账户、授权分组和供应商。
- 清除令牌后移除托管供应商和账户缓存。
- 未连接时隐藏 `tuzi-managed-*` 托管项，但保留默认项和用户自定义供应商。
- 用户自定义供应商使用 Tuzi API 地址时仍正常显示。
- 系统令牌 URL 参数中的 `+` 和 `/` 不被错误解析。
- Tuzi 集成默认开启并默认使用 `https://api.tu-zi.com`，只有显式配置 `VITE_TUZI_EMBEDDED_MODE=false` 才关闭，显式 API 地址可覆盖默认值。
- 账户接口携带系统令牌和用户 ID，请求失败时显示对应错误。
- 日志按页获取，默认不请求隐藏的汇总和模型数据。

定向 ESLint：本任务文件 0 error；仓库既有文件仍有 warning。

`pnpm build:web`：`web:typecheck` 通过；Vite 打包阶段因仓库现有 PPTX 导入模块无法解析 `pptx-glimpse` 而失败。本次 Tuzi 变更未修改该模块，合并最新上游后需要再次验证依赖状态。
