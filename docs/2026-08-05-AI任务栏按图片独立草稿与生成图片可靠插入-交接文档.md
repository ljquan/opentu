# AI 任务栏按图片独立草稿与生成图片可靠插入交接文档

**日期**：2026-08-05  
**适用版本**：`codex/fix-taskbar-draft-persistence`，基线 `origin/develop` `7f9e67d7`  
**关联 QA**：[2026-08-05-AI 任务栏按图片独立草稿与生成图片可靠插入-人工测试文档](../qa/2026-08-05-AI任务栏按图片独立草稿与生成图片可靠插入-人工测试文档.md)

## 问题

1. 选中生成图片后在任务栏继续补写提示词、添加参考素材或知识引用，未发送就误点其他位置时，后续内容可能被图片原始提示词覆盖或直接消失。
2. 不同图片之间可能错误沿用上一张图片的输入，未选图片时也可能显示上一张图片的提示词。
3. 生成图片在重试、恢复、局域网缓存或手动插入时，可能复用旧缓存、插入空白节点、显示错误尺寸或给出不清晰的失败提示。

## 最终行为

### 1. 每张图片独立保存草稿

- 草稿以图片元素 ID 隔离；图片 A 与图片 B 不共享输入。
- 每张图片保存当前页面内的：
  - 提示词；
  - 手动上传或从素材库添加的参考内容；
  - 知识库引用。
- 从 A 切到 B 时先保存 A；首次选择 B 时显示 B 自己的来源提示词和空的附加内容；重新选择 A 时恢复 A 的草稿。
- 如果图片来源提示词后来更新，仅在用户没有手动改写该提示词时同步新默认值；用户已编辑的内容保持不变。
- 只是任务栏失焦、但画布选区未变化时，当前输入保持不变。

### 2. 未绑定输入与图片草稿分离

- 未选中图片时显示独立的“未绑定草稿”，不会继续显示上一张图片的提示词。
- 点击画布空白导致取消图片选择时，当前图片草稿会保存，但任务栏切换到未绑定草稿；重新选中原图即可恢复该图片内容。
- 只有用户主动点击“关闭跟随”时，当前图片输入才会复制到未绑定草稿，同时停止对该图片的跟随。
- 主动关闭后，只要该图片仍保持当前选中状态就不会立即自动重新绑定；切换选择后可按正常规则再次绑定。

### 3. 提交与画板切换边界

- 绑定图片时，仅单张图片生成使用目标替换参数；多图生成保留原图并创建新图片，视频、文本和 Agent 模式也不替换该图片。
- 提交期间继续输入的新内容，不会被旧提交的完成或清理回调覆盖。
- 生成失败时保留原图片，并显示明确错误状态。
- 切换画板时清空所有图片绑定草稿，但保留未绑定草稿。
- 旧画板尚未结束的选区解析、内容解析或提交回调不能回写到新画板。
- 图片删除后回收对应草稿；位于 Frame 等容器内的嵌套图片仍存在时不会被误清理。

### 4. 生成图片缓存与插入

- 图片生成成功或任务恢复成功后，优先把远程结果缓存为稳定的 `/__aitu_cache__/...` 地址。
- 每次图片提交使用自己的 submission Request ID 作为缓存键；重试不会复用上一次提交的图片。
- 多张远程图片按顺序缓存，避免同一时间持有多个大 Blob。
- 任务列表主动插入图片时使用当前画板实例，先确认图片可加载，再创建画布节点；缓存缺失或图片加载失败时不留下空白节点。
- 缓存失败时允许回退到仍可访问的远程 URL，因此不把“远程图片必然离线可用”作为功能承诺。
- 错误文案统一为可识别的“图片缓存不可用”“图片加载失败，请检查图片地址或缓存”等信息，避免重复拼接“插入失败”。

### 5. 插入尺寸与批量布局

- 优先使用任务结果的真实宽高比例计算画布展示尺寸。
- 结果没有宽高时回退到请求 `size` 比例；两者都不可用时使用 `400 × 400`。
- 展示长边限制为 `600`，极端比例仍至少保留 `1px`，避免超大节点或非有限数值污染布局。
- 批量图片按同一组布局，并锁定已计算尺寸，防止异步加载后互相覆盖或重叠。

## 数据边界

- 图片草稿和未绑定草稿只保存在当前页面组件内存中，不写入画板 JSON、IndexedDB 或 `localStorage`。
- 刷新页面、关闭页面或重新挂载任务栏后，不保证恢复这些草稿。
- 模型、模型参数、生成数量、生成类型和动态画布选区不属于按图片草稿。
- 图片来源提示词只是该图片首次绑定时的默认值，不会作为所有图片的公共提示词。

## 性能与安全边界

- 草稿 Map 只保存当前页面中被实际编辑且仍存在的图片，恢复到默认值时移除冗余条目，图片删除后及时清理引用。
- 草稿中的附件与知识引用只复制数组，不复制图片二进制，不新增大对象持久化。
- 多图缓存采用顺序处理，降低并发下载产生的瞬时内存峰值。
- 远程缓存请求不携带站点凭据，并使用 `no-store` 与 `no-referrer`。
- 画板 ID 与 selection run ID 双重校验，阻止跨画板异步回写。

### 浏览器实测

在最新 `develop` 基线上对同一服务完成以下真实画布流程，并确认局域网地址 `http://192.168.50.225:7211/` 可访问：

- 图片 A 输入 `A-最新基线独立草稿` 后切出，再选 A 可恢复原文。
- 首次选择图片 B 时输入为空，不显示 A 的内容。
- 未选图片时恢复独立的 `未绑定草稿-最新`。
- 图片 B 输入 `B-最新基线独立草稿` 后切出，再选 B 可恢复原文。
- 首页本机与局域网访问均返回 `200`；未登录代理请求返回 `401 JSON`，符合鉴权预期。

## 剩余风险

- 当前没有覆盖完整 AIInputBar 画布交互的浏览器自动化用例，A/B/空白切换已通过人工浏览器实测，仍建议按关联 QA 做一次发布前回归。
- 真实供应商的缓存失败、极慢图片和多种极端比例依赖外部响应，需在目标部署环境人工验证。

## 一句话结论

任务栏现在按图片保存当前页面内的独立草稿，未选图片时使用独立输入；生成图片同时获得 submission 级缓存隔离、加载确认和受控尺寸插入。
