# 主画布原输入重抽验收（阶段一）

本阶段区分“再次生成 / 调整后生成 / 以此图修改”，不包含拖线创建生成框。自动验证未发送付费请求。

## 验收场景

| 操作 | 预期 |
| --- | --- |
| A/B/C 生成 D，选中 D 点再次生成 | 立即提交一张，顺序仍为 A/B/C，实际请求不包含 D；D 保留 |
| 再选中新结果重抽 | 仍使用原输入，不逐次累加结果图 |
| 原任务零参考图，选中结果重抽 | 仍是文生图，零参考图 |
| 点调整后生成 | 恢复原提示词、模型渠道、尺寸、参数和原批量数；不自动发送 |
| 删除 B，再选中 D、平移和缩放 | 预览与实际请求仅 A/C；B 和 D 不被加回；画布 B 保留 |
| 调整期间上传/粘贴替代图 | 新图出现在可删除参考列表；发送使用当前列表 |
| 点以此图修改 | 当前图片成为明确参考；蒙版行为沿用原入口 |
| 原任务 seed 固定且批量数大于 1 | 再次生成移除固定 seed，只提交一张；调整后生成保留原设置 |
| 删除原渠道，保留同名模型的其他渠道 | 提示恢复原渠道，不静默切换 |
| 原任务是以旧结果 X 为参考 | X 是合法原输入，不能因为它是生成图而被过滤 |
| 新结果保存画布、清理任务历史、刷新 | 从结果保存的记录恢复输入 |
| 导出含参考与蒙版的画布，清空测试缓存，再导入 | 原素材随备份恢复；仅删除本地缓存未备份时提示素材不可用 |
| 从任务列表手动插入历史结果 | 与自动插入一样保存可恢复输入 |
| 原记录完全缺失 | 明确提示重新添加原参考图或显式以此图修改，不猜测为空输入 |
| 回填、素材加载期间切板，快速重复点击 | 不向错误画板提交/插入；进行中的提交锁阻止快速重复请求 |

## 字段与兼容性

- `intent`、`boardId`、`sourceTaskId` 经工具栏/任务列表事件进入输入栏；编辑意图保存在目标草稿中。旧事件未提供意图时保持原行为。
- 实际任务复用既有 prompt / modelRef / referenceImages / params / canvasAssociations，不增加服务端表、环境变量或 SW 消息字段。
- `imageGenerationRecipe` 是元素可选字段，含版本、原任务 ID、轻量输入；参考图及蒙版使用缓存 URL。自动插入、手动插入、通用媒体元数据绑定均保留它。
- `sourceElementId` 仅在来源元素及 URL 版本一致时用于绑定。复制至其他画板或来源已替换时使用保存素材，不绑定错误节点。
- 旧图片没有 recipe 时回退至完整持久化任务；缓存失败时保留生成结果和任务 ID。无法恢复的旧历史不会自动补造记录。
- 当前没有媒体自动逐出；若以后引入，需要保留 recipe 引用。明确删除缓存仍可能使原素材不可用。

检查记录见 `openspec/changes/add-canvas-reroll-and-reference-connections/validation.md`。完整复制/粘贴、撤销、蒙版交互和真实模型请求仍需人工验收；JSON 往返测试不代表完整浏览器生命周期验收。
