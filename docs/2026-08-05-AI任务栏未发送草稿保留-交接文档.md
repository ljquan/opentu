# AI 任务栏未发送草稿保留交接文档

更新日期：2026-08-05

## 背景与问题

用户在 AI 任务栏输入提示词、添加上传内容或选择知识引用后，如果尚未发送就误触画布空白、其他控件或切换绑定图片，输入区域可能因交互状态变化而丢失未发送内容。用户只能重新输入或重新选择引用，容易造成编辑中断和内容遗漏。

本次修复将“失去焦点或画布选择变化”与“清理输入草稿”拆开：普通界面交互只改变焦点、面板开关或当前画布绑定目标，不再清空尚未发送的输入草稿。

## 最终行为

- 输入提示词后点击画布空白或其他控件，提示词保持原样。
- 已添加的上传内容和知识引用在上述误触后继续保留。
- 从未绑定状态进入图片绑定状态，或从一张绑定图片切换到另一张图片时，未发送草稿保持不变。
- 当前画布选择和绑定图片仍随用户操作正常变化，不会被错误固定为草稿的一部分。
- 发送成功后沿用既有清理规则：普通任务栏提交会清空本次输入，绑定图片模式仍保持原有连续编辑行为；发送失败或尚未发送时不清空。
- 用户主动删除上传内容、移除知识引用、清空提示词或确认覆盖输入时，仍按原有交互执行。

## 最小设计边界

本次只调整 AI 任务栏在组件仍存活期间的草稿生命周期，不改变生成工作流、模型选择、参数、数量、提示词历史或图片绑定规则。

草稿由任务栏现有状态承载，普通 `blur`、画布点击、工具栏操作和绑定目标变化不能触发草稿清理。只有已有的明确业务动作可以更新或清理对应内容：

1. 用户继续输入、上传、删除或选择知识引用。
2. 用户确认使用外部回填内容覆盖当前输入。
3. 工作流提交成功后按当前生成模式执行既有清理逻辑。
4. 用户执行已有的显式清理操作。

不新增全局事件监听、轮询、图片二进制副本或无上限缓存，避免额外常驻内存和重复资源持有。

## 涉及状态

| 状态                   | 草稿职责                                 | 保留边界                                                               |
| ---------------------- | ---------------------------------------- | ---------------------------------------------------------------------- |
| `prompt`               | 用户尚未发送的提示词全文                 | 普通失焦、画布误触和绑定图片切换时保留                                 |
| `uploadedContent`      | 用户主动上传或回填的图片、视频等参考内容 | 普通失焦和画布选择变化时保留；用户删除或提交后按当前模式的既有逻辑处理 |
| `knowledgeContextRefs` | 用户选择的知识库引用                     | 普通失焦和画布选择变化时保留；用户移除或提交后按当前模式的既有逻辑处理 |
| `selectedContent`      | 当前画布选择派生的图片、图形、视频或文字 | 继续随画布选择变化，不作为固定草稿持久保存                             |
| `boundImageTarget`     | 当前任务栏跟随的画布图片                 | 可随选择切换；切换时不得连带清空前三项草稿状态                         |

模型、生成类型、参数和生成数量继续使用现有偏好与交互逻辑，本次不修改其持久化策略。

## 清理与持久化边界

- **发送成功**：普通任务栏提交继续清空输入；绑定图片模式继续沿用现有连续编辑行为，本次不改变两者的清理时机。
- **发送失败**：保留草稿，便于用户修正或重试。
- **显式清理**：用户主动删除或确认覆盖时，允许更新或清理对应草稿内容。
- **页面刷新**：本次不把未发送草稿写入 `localStorage`、IndexedDB、服务端或白板业务数据；刷新页面、关闭页面或组件真实卸载后不承诺恢复草稿。
- **跨白板/跨设备**：不提供同步或恢复能力，不新增数据结构、数据库字段和迁移。

## 回归边界

- 不改变图片目标的跟随、解除跟随和原位替换规则。
- 不改变模型、参数、数量及生成类型切换行为。
- 不改变外部回填前的覆盖确认流程。
- 不改变提示词历史写入时机，仅在真实提交后沿用现有记录逻辑。
- 不将当前画布选择错误地长期保留为用户上传内容。

## 一句话结论

AI 任务栏未发送的提示词、上传内容和知识引用会在普通误触及绑定图片切换时保留；提交、显式清理和页面刷新仍遵循各自原有边界。
