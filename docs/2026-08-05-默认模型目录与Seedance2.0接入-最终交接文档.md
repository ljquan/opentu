## 4. OpenTu 模型目录与数据边界

模型广场仍是运行时模型、endpoint、价格和能力数据源，本次不写入、不补齐也不重组模型广场数据。OpenTu 静态目录仅负责默认选择器展示、排序、`NEW` 标记和历史模型隐藏。

数据流：

1. OpenTu 从自身静态目录取得 9 个新增模型的展示名称、模型 ID、类型和排序信息。
2. OpenTu 读取既有运行时发现结果，并按模型 ID 与供应商来源合并。
3. 默认选择器应用 OpenTu 本地隐藏清单；历史解析和非默认 Profile 不应用该过滤。
4. 价格、分组、渠道和 endpoint 继续使用后端现有返回，不创建虚拟 `default`，不复制来源分组价格，也不增加路由回退。

调用是否可用仍取决于既有后端分组、价格、渠道和上游能力。本次只保证 OpenTu 正确展示和提交，不承诺为缺少后端配置的模型补建调用能力。

## 5. Seedance 2.0 官方接口

### 5.1 创建任务

```http
POST /v1/videos
Content-Type: application/json
```

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "生成一个日出场景"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false,
  "seed": 0,
  "camera_fixed": false
}
```

### 5.2 参数边界

| 参数             | 支持范围                                                | 默认值  |
| ---------------- | ------------------------------------------------------- | ------- |
| `duration`       | 4-12 的整数                                             | `5`     |
| `resolution`     | `480p`、`720p`、`1080p`                                 | `720p`  |
| `ratio`          | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive` | `16:9`  |
| `generate_audio` | 布尔值                                                  | `true`  |
| `watermark`      | 布尔值                                                  | `false` |
| `seed`           | 整数；留空不传                                          | 不传    |
| `camera_fixed`   | 布尔值；支持显式 `false`                                | 不传    |

OpenTu 在提交前校验参数并保留正确 JSON 类型；显式 `seed: 0` 和 `camera_fixed: false` 不会被当成空值丢弃。后端与上游校验沿用部署环境既有行为，不属于本次修改范围。

### 5.3 参考媒体

- 文本：`content[].type = text`。
- 参考图：`image_url` 与 `role: reference_image`。
- 参考视频：`video_url` 与 `role: reference_video`，只接受公网 HTTP(S) URL。
- 参考音频：`audio_url` 与 `role: reference_audio`，接受公网 HTTP(S)、合法音频 Data URL 和素材 ID。
- 音频 Data URL 必须为合法 MIME/Base64，最大 16 MiB；批量或更大音频应使用公网 URL 或素材 ID。
- OpenTu 会在创建任务前拒绝 Blob URL、私网/本机参考视频、非法 MIME、非法 Base64 和空主机 URL。

### 5.4 轮询与结果

```http
GET /v1/videos/{taskId}
```

- `queued`、`processing`：继续轮询并更新任务进度。
- `completed`、`succeeded`：读取内联视频 URL；没有 URL 时读取 `/videos/{taskId}/content`。
- `failed`、`error`：立即结束并展示上游错误。
- 网络错误、408、425、429 和 5xx：有界退避重试。
- 其它确定性 4xx：立即失败，不重复创建任务。
- 轮询支持取消、最大次数和连续错误上限，不进行无限请求。
