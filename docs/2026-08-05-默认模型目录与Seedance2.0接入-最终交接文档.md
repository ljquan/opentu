## 1. 最终结论

本次变更完成默认模型目录刷新，并将 Seedance 2.0 前后端调用统一到官方 `POST /v1/videos` JSON 异步接口：

- `default` 新增 GPT-5.6、DeepSeek V4、Seedance 2.0 共 9 个模型，显示 `NEW`，新版本优先展示。
- GPT-5.4 及以下共 18 个旧 GPT 模型仅从 `default` 隐藏，不删除模型、价格、渠道和历史引用。
- `gpt-5.5` 继续保留在 `default`。
- 新模型不增加灰度或额外产品权限开关；实际调用仍要求用户分组、价格和上游渠道可用。
- Seedance 2.0 的分辨率、比例、时长、参考媒体和可选控制字段均按官方接口校验并透传。
- Seedance 1.x 保持原调用链，不受 2.0 适配器影响。

本次未部署，也未使用真实 API Key 执行上游视频生成、轮询和下载。

## 4. 模型目录、价格与路由

模型广场数据是目录、endpoint、价格与能力的主要数据源。OpenTu 静态目录用于首屏展示、排序和运行时发现不可用时的兜底，不替代模型广场数据。

数据流：

1. tuzi-api 读取模型广场的模型、分组、供应商、endpoint 和分组价格。
2. 9 个新增模型获得 `default` 展示归属；旧模型只移除 `default` 展示归属。
3. 缺少直接 `default` 价格时，按来源分组复制同一 endpoint 的价格。
4. OpenTu 合并静态目录与运行时发现结果，按模型 ID 去重并应用统一排序。
5. 用户调用仍使用 `default` 权限和价格语义；仅在默认组没有候选渠道时执行来源分组回退。

来源分组优先级：

| 模型系列     | 回退顺序                            |
| ------------ | ----------------------------------- |
| GPT-5.6      | `原价分组` -> `官方优惠` -> `Codex` |
| DeepSeek V4  | `原价分组`                          |
| Seedance 2.0 | `原价分组`                          |

Seedance 三个型号的模型广场快速调用元数据和计费说明已统一到 `480p`、`720p`、`1080p`，移除未被当前官方契约支持的 4K 档位。四个已知历史内置 `rule_version` 会被精确迁移；当前版本、局部修改和自定义规则不会被覆盖。

## 5. Seedance 2.0 官方接口

### 5.1 创建任务

```http
POST /v1/videos
Content-Type: application/json
```

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "生成一个日出场景"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false,
  "seed": 0,
  "camera_fixed": false
}
```

### 5.2 参数边界

| 参数             | 支持范围                                                | 默认值  |
| ---------------- | ------------------------------------------------------- | ------- |
| `duration`       | 4-12 的整数                                             | `5`     |
| `resolution`     | `480p`、`720p`、`1080p`                                 | `720p`  |
| `ratio`          | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive` | `16:9`  |
| `generate_audio` | 布尔值                                                  | `true`  |
| `watermark`      | 布尔值                                                  | `false` |
| `seed`           | 整数；留空不传                                          | 不传    |
| `camera_fixed`   | 布尔值；支持显式 `false`                                | 不传    |

OpenTu 在提交前校验参数；tuzi-api 在模型映射后、计价前再次校验，`doubao` 和 `seedanceproxy` 两条路由均执行相同官方约束。显式 `seed: 0` 和 `camera_fixed: false` 不会被当成空值丢弃。

### 5.3 参考媒体

- 文本：`content[].type = text`。
- 参考图：`image_url` 与 `role: reference_image`。
- 参考视频：`video_url` 与 `role: reference_video`，只接受公网 HTTP(S) URL。
- 参考音频：`audio_url` 与 `role: reference_audio`，接受公网 HTTP(S)、合法音频 Data URL 和素材 ID。
- 音频 Data URL 必须为合法 MIME/Base64，最大 16 MiB；批量或更大音频应使用公网 URL 或素材 ID。
- Blob URL、私网/本机参考视频、非法 MIME、非法 Base64 和空主机 URL 会在创建任务前被拒绝。

### 5.4 轮询与结果

```http
GET /v1/videos/{taskId}
```

- `queued`、`processing`：继续轮询并更新任务进度。
- `completed`、`succeeded`：读取内联视频 URL；没有 URL 时读取 `/videos/{taskId}/content`。
- `failed`、`error`：立即结束并展示上游错误。
- 网络错误、408、425、429 和 5xx：有界退避重试。
- 其它确定性 4xx：立即失败，不重复创建任务。
- 轮询支持取消、最大次数和连续错误上限，不进行无限请求。
