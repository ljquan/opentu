# 生成框验收

本地实现与模拟供应商验收已完成。真实供应商和触摸设备仍需上线前验收；自动执行整张图不在本期范围。

1. 选中图片 A，从连接点拖到空白处，选择“图片”。落点出现生成框，A 成为参考，尚未发送请求。Escape 取消菜单后不留空线。
2. 将 B 拖到该框：参考顺序 A/B，重复连入 B 不增加条目。不同画布图片即使地址相同也保留两项。
3. 选中框，在卡片旁的编辑器填写提示词、模型、参数、数量。点击发送；生成后草稿保留，结果不自动加入参考。
4. 删 B 的缩略图或输入线：两处同步，源图保留；撤销/重做后顺序恢复。移动或旋转来源，线端点跟随。
5. 删除源图：显示缺失提示并禁止发送；撤销删除恢复引用。删除生成框不删除已完成结果，已提交任务继续由任务队列处理。
6. 一起复制生成框与来源：绑定新图片；只复制框：保留媒体参考，不指向目标画板上同名 ID。刷新后提示词、模型、参数、引用及有效连线恢复。
7. 切换视频：按模型设置普通参考、首帧、尾帧。超出数量、重复首帧、仅有尾帧、角色不匹配均应阻止发送，不能悄悄截断或转换角色。
8. 退出生成框编辑，确认进入前的输入草稿恢复。重新选中生成框可继续编辑；保存的模型/渠道失效时保留配置并提示。
9. 切板期间等待输入读取：未提交的操作取消；已提交任务完成后只进入原所属画板或等待原画板恢复，不进入当前其他画板。
10. 导出含本地参考图和蒙版的画布备份，清理测试缓存后导入，确认素材可读。未知生成框版本必须保留数据并提示。

代码校验和本地浏览器结果见 `openspec/changes/add-canvas-reroll-and-reference-connections/validation.md`。所有测试使用独立浏览器数据，不修改实际用户的模型凭据、任务和画板。

## 交互打磨 B

- 图片端口拖空白：纵向菜单展示文本、图片、视频、快捷编辑、普通连线。文本仅回填原图；快捷编辑打开裁剪/滤镜等已有编辑器；音频与 3D 生成链路未纳入本阶段。
- 拖动时观察曲线预览、目标卡片高亮、松手追加引用；同一图片重复连入不增加条目。取消菜单或刷新不保存临时线；普通连线选择后才进入历史。
- 卡片显示缩略图、提示词、模型和数量；编辑器就近放置，空间不足时放在下方。点击空白或其他元素自动收起，再选卡片恢复。
- 编辑器打开时，依次删除参考缩略图、撤销、重做，核对引用数和曲线始终一致。额外验证参数修改的撤销/重做不会被回填时的自动保存覆盖。
- 移动源图/卡片，缩放、平移后刷新，核对两根曲线分别接入独立端口，提示词和引用保留。

## 图片框与连接按钮回归

- 单击卡片标题、正文、底部摘要可打开；收起后单击再次打开，拖动卡片不误开。
- 100% 和 70% 缩放下，图片“＋”按钮保持 24px，距圆心 20px 处仍可点击和拖线。
- 左右方向分别拖空白创建卡片：参考图自动进入，曲线从相向边缘连接；移动来源跨过卡片时端口跟随换边，撤销可恢复。
- 工具栏、输入栏不盖住图片连接按钮；图片缩放/旋转控制仍可使用。
- 刷新后不打开菜单也显示统一选中边框；缓存图片在卡片内可显示缩略图。
- 2026-11-11 本地鼠标验收通过（70%/100%、左右拖线及刷新），触摸设备和旋转图片实拖待验收。

## 生成卡片操作栏修复（2026-11-16）

- 原因：生成卡片和参考连线被普通形状工具栏过滤，选中卡片后没有可见删除入口。
- 修复：复用现有浮动定位，为生成卡片显示带文字的“编辑 / 复制 / 删除”按钮；选中参考连线时只显示删除。保持原生删除、复制和历史逻辑，无新增持久化字段或迁移。
- 本地浏览器实测：选中图片生成卡片后显示工具栏；点击删除时卡片、对应输入线、编辑器一并消失，源图和其他卡片保留；Cmd+Z 恢复卡片与引用线，Cmd+Shift+Z 再次删除。
- 本地浏览器实测：复制保留参考图；Backspace 删除选中的副本；编辑提示词时 Backspace 仅删除文字。测试后恢复原提示词并删除测试副本。
- 刷新后重新选中卡片，三个操作按钮正常显示，原参考图及连线保留。
- 回归测试：5 个文件、27 项通过，覆盖图片/视频卡片删除、保留源图与生成结果、撤销/重做、单独断开输入线、编辑事件及画布/输入栏同步。
- drawnix 与 web TypeScript 检查、web 生产构建通过。本次不涉及生成请求，未额外调用付费图片或视频供应商。
