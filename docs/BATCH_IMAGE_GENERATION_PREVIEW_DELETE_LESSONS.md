# 批量出图预览单张删除经验

## 背景

批量出图完成后，预览列只能查看、放大和下载，无法清理不满意的单张结果。删除整行又会同时丢失提示词、参数和其他正常图片。

本功能在行内缩略图和完整画廊中增加单图删除入口，只删除选中的生成结果，不影响同一行其他图片，也不删除已插入画布的图片元素。

## 最终行为

- 完成、生成中和部分成功状态下，已生成图片均可单独删除。
- 行内缩略图与“查看全部”画廊复用同一删除行为。
- 点击删除按钮不会触发图片放大或打开画廊。
- 删除前显示危险操作确认；取消确认不修改数据。
- 删除后预览、数量、下载和 Excel 导出均按剩余任务重新计算。
- 刷新页面后被删除结果不会恢复。

## 删除边界

批量出图行通过 `taskIds` 关联任务队列。删除时同时：

1. 从当前行移除目标任务 ID。
2. 通过既有任务队列删除该任务记录并持久化。

删除入口不扫描或复制图片二进制，不清理统一媒体缓存，也不查找画布上引用相同 URL 的元素。因此已插入画布的图片仍保持原样。

## 交互与可访问性

- 桌面端在缩略图悬停或按钮聚焦时显示删除按钮。
- 不支持悬停的触屏设备始终显示。
- 删除按钮提供中英文 `aria-label` 和 `title`。
- 尊重 `prefers-reduced-motion`，不增加不必要动画。

## 关键实现

- 预览渲染保留任务对象和 URL，以任务 ID 为稳定身份。
- 确认后按稳定的行 ID 定位当前行，避免弹窗期间行顺序变化导致误删。
- 行内预览、部分成功预览和完整画廊共享删除处理器。
- 仅更新目标行和对应任务，不创建 Object URL，不读取或复制图片内容。

## 一句话结论

预览单张删除应同时解除当前行关联并删除任务记录，使预览、下载、导出和刷新结果一致，同时保留已插入画布的图片。
