## 背景

AI 任务栏跟随单张图片时，当前图片既是参考输入，也是原位替换目标。原有 `X` 操作会同时移除目标缩略图，无法满足“停止位置吸附和覆盖，但继续使用刚才点击的图片作为参考图”的需求。

本功能将“参考图片”和“跟随、覆盖目标”拆开，并提供临时与按图片永久生效的两种选择。

## 最终交互

- 单选图片进入跟随状态后，任务栏右上方继续显示 `X` 按钮。
- 点击 `X` 等同于“本次只作参考图”。
- `X` 旁新增下拉按钮，菜单包含：
  - `本次只作参考图`
  - `对此图始终只作参考图`
- 进入仅作参考模式后，任务栏回到底部，不再跟随图片移动。
- 当前图片继续显示在任务栏缩略图中，名称改为“参考图”。
- 当前图片保持为生成请求的第一张参考图，但不再作为原位替换目标。
- 提示词、模型、尺寸、数量、手动参考图和知识库上下文保持不变。
- 打开对话抽屉不会取消当前图片选择，抽屉继续显示并提交同一张参考图。

## 临时与永久模式

| 模式                 | 生效范围     | 重新选择图片                     | 刷新白板           |
| -------------------- | ------------ | -------------------------------- | ------------------ |
| 本次只作参考图       | 当前选择会话 | 取消选择后再次选择会恢复默认跟随 | 不保留临时状态     |
| 对此图始终只作参考图 | 当前图片元素 | 再次选择仍只作参考图             | 随白板数据继续生效 |

永久模式只在对应图片元素上保存轻量布尔字段 `aiTaskbarReferenceOnly: true`。其他图片仍保持原有任务栏跟随和原位替换行为。

## 生成数据边界

进入临时或永久仅作参考模式后：

- 当前图片位于 `referenceImages` 第一项。
- 手动添加的其他参考图继续保留，并排在当前图片之后。
- 原图片内容、元素 ID、位置和尺寸保持不变。
- 生成结果按普通流程作为新图片插入画布。
- 生成任务不得携带原目标的以下字段：
  - `replaceElementId`
  - `targetElementId`
  - `anchorId`
  - `sourceTaskId`
  - `sourcePrompt`

未进入仅作参考图模式时，既有单图原位替换和多图独立生成逻辑保持不变。

## 状态与性能边界

- 临时模式只复用当前图片元素 ID，不写入持久化存储。
- 永久模式只增加一个图片元素布尔字段，不保存图片内容、Base64 或无界 ID 列表。
- 图片继续复用现有 URL，不复制二进制数据，不创建额外 Object URL。
- 菜单操作会保留当前图片选择，避免 Portal 交互被画布误判为取消选择而丢失参考图。
- 同一图片的参考状态使用稳定键去重，避免鼠标移动时重复保存草稿和刷新布局。
- 不新增常驻监听器、轮询任务、数据库表或迁移。
