# 图片预览实际尺寸显示交接文档

更新日期：2026-08-10

## 需求与最小范围

统一图片预览需要显示与任务栏一致的上游图片实际像素尺寸，例如 `1023×1537`。

本次最小完整范围如下：

- 从任务列表打开图片预览时，直接透传完成任务的 `result.width`、`result.height`。
- 从画布打开生成图片预览时，通过画布节点关联的生成任务读取同一尺寸。
- 为任务栏手动插入的图片补充任务关联；自动插入继续复用已有关联。
- 当前目标图片无法通过任务关联取得尺寸时，允许按图片 URL 回查已有完成任务。
- 尺寸缺失或非法时不显示，不使用请求尺寸、画布几何尺寸、图片自然尺寸或比例文本兜底。
- 视频、音频及现有预览操作保持不变。

本次不新增后端接口、数据库实体、数据迁移、权限能力，也不调整图片生成尺寸解析链路。

## 架构与数据流

### 任务列表预览

1. 图片任务完成后，既有任务链路把上游实际宽高持久化到 `task.result.width` 和 `task.result.height`。
2. `getImageTaskResultDimensions` 校验宽高必须为正的安全整数。
3. `TaskQueuePanel` 和 `DialogTaskList` 构造预览项时透传有效宽高。
4. `MediaViewport` 仅在当前媒体为图片且宽高有效时显示 `宽×高`。

### 画布预览

1. 任务栏手动插入图片时，将任务 ID 写入画布图片节点的 `generationTaskId`；自动插入沿用既有写入逻辑。
2. 双击画布图片后，预览立即打开，当前目标图优先解析尺寸。
3. 尺寸解析按 `generationTaskId -> getTask -> getCompleteTask` 读取当前浏览器应用上下文中的本地任务数据。
4. 当前目标图片缺少任务 ID，或任务 ID 查询无法取得有效尺寸时，才允许按结果 URL 回查已有完成任务；其他关联图片不会逐图扫描历史任务。
5. 其余关联图片串行解析后一次批量合并，避免每张图片都复制完整预览数组。
6. 请求序号以及图片 `id`、`url`、`type` 校验阻止关闭预览、切换画板或快速切图后的陈旧结果回写。

编辑操作覆盖原图片内容时会清除旧 `generationTaskId`，避免新图片继续显示旧任务尺寸。

## 复用点

- 从任务栏原有尺寸格式化校验中提取共享的 `getImageTaskResultDimensions`，保证任务栏与预览采用同一规则和数据源。
- 复用任务服务的 `getTask`、`getCompleteTask` 和结果 URL 查询能力，不增加网络请求或新接口。
- 复用 IndexedDB `aitu-app/tasks` 的完成任务持久化，以及既有画布节点持久化机制。
- 复用统一 `MediaViewport`，任务抽屉、对话框任务列表和画布预览共用同一展示组件。
- 复用自动插入已有的 `generationTaskId` 关联，仅补齐手动插入路径。

## 关键实现

- 图片预览项新增可选 `width`、`height` 字段；显示格式固定为 `宽×高`。
- 展示值只来自图片任务结果，不读取请求参数、画布缩放宽高或比例文案。
- 空值、零值、负数、小数、非安全整数及非图片媒体均不渲染尺寸区域，也不增加额外分隔线。
- 画布尺寸查询失败时返回空结果，图片预览仍可正常打开。
- 同一次预览解析中，对任务 ID、图片 URL 和回查策略完全相同的来源复用查询结果，减少重复读取。
- 目标图先更新，其余图片集中更新，降低大量图片预览时的数组复制和 React 渲染次数。

## 持久化与权限边界

- 不新增后端、数据库表、IndexedDB 表或字段迁移。
- `generationTaskId` 随既有画布图片节点保存；任务宽高继续保存在既有 `task.result` 中。
- 只读取当前浏览器应用上下文可访问的本地任务数据，不扩大既有 origin 级存储读取范围，不新增鉴权入口；不同登录用户间的隔离仍需人工复核。
- 不保存 API Key、访问令牌、完整上游响应或额外图片副本。
- URL 回查只匹配已有完成图片任务，不修改任务状态、图片 URL 或历史数据。

## 剩余风险

- 在已打开预览中导航到另一张没有 `generationTaskId` 的存量图片时，不会主动按 URL 回查；直接双击该目标图片打开预览可以正常回查。这是为避免对所有存量图片逐张扫描历史任务而保留的性能边界。
- 尚未完成跨浏览器、真实存储故障、快速切换和大批量图片性能测试，相关兼容性与极端并发风险仍需按人工测试文档补充验证。

## 一句话结论

图片预览现在与任务栏共用上游最终图片的实际宽高；缺少可信任务结果时宁可不显示，也不会用请求比例或画布尺寸代替。
