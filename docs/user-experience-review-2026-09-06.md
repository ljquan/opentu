## 检查范围

通过真实 Chromium 浏览器操作表单，使用临时账号，覆盖注册、刷新、登录、改密、退出，以及 1440、390、320 像素宽度。测试账号随后删除。没有调用模型供应商。本次不代表全应用或所有浏览器验收。

## 已修复并部署

1. **切换窗口丢失密码**：匿名用户填写注册密码后，切换窗口再返回，会话刷新返回 401 并清空表单密码。浏览器已复现。现在仅在已登录会话失效或身份发生变化时清理密码；已加入浏览器回归检查。
2. **注册后退出仍显示注册表单**：代码中的注册模式未在退出时重置。现在退出统一返回登录，已用“注册成功后立即退出再登录”验证。
3. **名称只有空格仍可提交**：增加提交前校验和中文提示。已验证不会进入注册请求。
4. **断网错误不友好**：网络失败改为中文提示，按钮恢复可重试。通过浏览器拦截并中断登录请求验证。

## 尚未解决，影响完整产品使用

1. **登录后无法进入工作区（高优先级）**：当前只有账号信息和改密/退出功能，没有创作入口。完整工作区的账户隔离尚未完成，不能只加一个跳转链接就认定解决。
2. **忘记密码无法自助恢复（高优先级）**：邮件服务、身份验证与重置流程未接入。
3. **邮箱尚未验证（高优先级）**：注册成功不代表已证明邮箱归属，公网开放前需完成验证策略。
4. **访问依赖本机隧道（高优先级）**：域名、ICP 和 HTTPS 尚未解决，其他用户不能使用 localhost 地址访问该服务。
5. **动效交付与描述不一致（低优先级）**：页面仍有英文标语；现有表单入场动画不等于登录/注册切换动画。上一轮描述过度，本次未将其算作已修复。
