# AI 任务栏跨媒体目标控制交接文档

- **状态**：现行设计
- **最后更新**：2026-08-11

## 背景

AI 生成的图片、视频、音频和文本插入画布后，用户应能在同一条 AI 任务栏中继续复用原提示词、编辑目标并提交同类型生成。目标控制同时包含两类容易混淆的行为：任务栏是否吸附在目标附近，以及生成结果是否原位替换目标。

本文是跨媒体目标控制的唯一现行说明。日期命名的交接文档保留具体问题的历史背景与验证记录；其描述与本文冲突时，以本文为准。

## 术语

- **目标绑定**：任务栏识别当前单选的生成目标，并恢复该目标的生成类型、提示词候选和草稿。
- **位置跟随**：任务栏在桌面端吸附到目标附近。它只影响位置，不改变目标绑定或生成语义。
- **原位替换**：同类型单结果生成成功后，更新当前目标内容和生成元数据，同时保留其画布身份与几何信息。
- **仅作参考**：图片或视频继续作为生成上下文，但不再作为原位替换目标。
- **仅作上下文**：文本正文继续作为生成上下文，但不再作为原位替换目标。
- **虚化提示词**：目标的历史提示词只作为 ghost suggestion 显示，用户明确采纳后才进入真实输入值。

不要再用“关闭跟随”同时表示关闭位置吸附和取消原位替换。位置开关只控制吸附；`X` 和关闭方式菜单负责切换到仅作参考或仅作上下文。

## 四媒体能力矩阵

| 目标类型 | 进入目标绑定                           | 虚化提示词与逐目标草稿 | 位置跟随控件               | 绑定提交             | 参考 / 上下文模式                |
| -------- | -------------------------------------- | ---------------------- | -------------------------- | -------------------- | -------------------------------- |
| 图片     | 任意单选图片；普通图片使用空提示词     | 支持                   | 支持                       | 单结果同类型原位替换 | 本次或始终仅作参考图             |
| 视频     | 仅有生成元数据或明确任务 ID 的生成视频 | 支持                   | 支持                       | 单结果同类型原位替换 | 本次或始终仅作参考视频           |
| 文本     | 仅有生成元数据或明确任务 ID 的生成文本 | 支持                   | 支持                       | 单结果同类型原位替换 | 本次或始终仅作上下文             |
| 音频     | 仅有生成元数据或明确任务 ID 的生成音频 | 支持                   | 沿用目标定位，但不显示开关 | 单结果同类型原位替换 | 不支持，避免暗示存在音频参考输入 |

普通手写文本、手动导入视频和手动导入音频没有生成元数据时，继续使用普通画布选区行为。系统不得通过正文内容或媒体 URL 模糊扫描任务历史来猜测生成来源。

## 虚化提示词

### 显示与采纳

目标存在历史提示词且当前输入为空时，任务栏以淡化 placeholder 显示：

```text
按空格或回车复用提示词：{目标提示词}
```

提示词候选不写入 textarea 的 `value`。在没有组合键且输入法不处于组合状态时，按空格或回车只把候选写入输入框，不立即提交；再次按回车才走原有提交流程。

### 取消与异步边界

- 用户直接输入其他字符或操作任务栏其他控件时，立即取消候选。
- 同一目标选择周期内，候选被取消后不会因为输入再次清空或异步元数据刷新而重新出现。
- 切换目标后，按新目标重新建立候选；旧目标的异步解析结果不得覆盖当前目标。
- 取消选择、多选或选择不支持的内容后，不显示目标提示词候选。

## 逐目标草稿

- 草稿按“媒体类型 + 元素 ID”隔离，避免不同类型或不同元素串用状态。
- 每个目标保留当前页面内的提示词、手动参考内容和知识库引用。
- 首次选择生成目标时，以其生成提示词作为候选；普通图片以空提示词开始。
- 切换目标时先保存当前草稿，再恢复新目标自己的草稿。
- 同一目标的来源提示词更新时，只更新未被用户编辑的默认状态，不覆盖用户草稿。
- 未绑定状态使用独立草稿，不继续显示上一个目标的内容。
- 草稿只存在于当前 React 会话；切换画板时清理目标草稿，不写入画板 JSON、IndexedDB 或 `localStorage`。

## 位置跟随开关

图片、视频和文本目标在桌面端复用同一组跟随控件：

- 开启时，任务栏优先显示在目标下方，空间不足时显示在上方，并限制在当前视口内。
- 关闭时，任务栏回到底部，只隐藏参考 / 上下文切换入口；目标缩略图、目标草稿、模型参数、知识库引用和原位替换绑定均保持不变。与其他任务栏控件一致，点击开关会取消尚未采纳的虚化候选。
- 重新开启后，无需重新选择目标，任务栏立即恢复吸附。
- 偏好按浏览器 origin 保存在 `localStorage`；无历史值、非法值或读取失败时默认开启。
- 移动端继续使用底部布局，控件不得相互遮挡。

音频目标沿用既有目标定位，但不显示位置开关、`X` 或关闭方式菜单，也不宣称支持音频参考输入。

## 仅作参考与仅作上下文

位置跟随开启时，图片、视频和文本目标显示 `X` 与关闭方式菜单：

- `X` 等同于本次仅作参考 / 上下文。
- 菜单提供“本次”与“始终”两种选择。
- 临时选择只在当前选择会话生效；取消选择后再次选择目标，恢复默认绑定替换行为。
- 永久选择在对应画布元素上保存轻量 reference-only 标记；重新加载画板后仍保持参考 / 上下文模式，其他元素不受影响。
- 进入该模式后，任务栏回到底部，当前图片、视频或文本仍作为对应生成上下文，但提交不得携带该目标的原位替换参数。
- 提示词、模型、参数、手动参考内容和知识库引用保持不变。

图片显示“参考图”，视频显示“参考视频”，文本显示“上下文”；不得用图片文案代替其他媒体类型。

## 同类型原位替换

目标绑定且未进入参考 / 上下文模式时，提交会创建新的同类型生成任务，而不是重试旧任务。单结果成功后：

- 图片更新资源 URL 和生成元数据。
- 视频更新视频资源和生成元数据。
- 音频更新音频资源和生成元数据。
- 文本更新正文和生成元数据，并在自动尺寸变化后刷新任务栏位置。

替换保留目标元素 ID、位置、尺寸、层级和选择上下文；失败或目标在生成期间被删除时，保留原内容且不插入孤立结果。

图片批量生成是明确例外：生成数量为 `1` 时原位替换；数量大于 `1` 时保留原图，并按独立 anchor 和批次槽位插入新图。

## 元数据与安全性能边界

- 画布元素只保存 `generationPrompt`、`aiPrompt`、`generationTaskId` 等轻量来源信息；图片额外兼容 `generationAnchorId`。
- 非图片资产的遗留 `prompt` 只作为 `AI_GENERATED` 来源的兼容字段；本地或手动导入入口不得用它保存描述性文字，避免把普通素材误识别为生成目标。
- anchor 和任务参数只传递目标元素 ID、anchor ID、来源任务 ID、来源提示词和替换关系。
- 不把 Blob、Base64、完整任务历史或媒体二进制写入画布元素、anchor 或目标草稿。
- 非图片目标仅通过元素元数据或明确任务 ID 点查提示词，不在选区刷新时扫描任务历史。
- 目标状态键包含媒体类型；异步目标解析使用运行序号丢弃过期结果。
- 视口变化继续通过 `requestAnimationFrame` 合并位置刷新；取消选择后不再计算目标位置。
- 原位更新目标，避免删除并重建元素造成布局抖动或不必要的大对象复制。

## 图片局域网专项

局域网 HTTP 页面可能无法启用 Service Worker。图片稳定虚拟 URL、Vite 同源代理、IndexedDB Blob 降级、Object URL 回收和生成结果插入规则，见 [AI 任务栏跟随尺寸与局域网图片插入专项](./2026-08-04-AI任务栏跟随尺寸与局域网图片插入-交接文档.md)。

该专项只处理图片请求、缓存、渲染和插入可靠性，不定义视频、音频或文本的目标控制语义。

## 一句话结论

AI 任务栏为图片、视频、音频和文本生成目标统一提供虚化提示词、逐目标草稿与同类型原位替换；图片、视频和文本还可独立控制位置跟随，并切换为仅作参考或仅作上下文。
