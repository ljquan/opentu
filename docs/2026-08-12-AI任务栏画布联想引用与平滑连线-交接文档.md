# AI 任务栏画布联想引用与平滑连线交接文档

更新日期：2026-08-12

## 背景

AI 任务栏原有附件入口与画布选择属于两条独立链路，用户无法在提示词中明确表达“使用画布上的这个对象作为参考”，生成任务与来源素材之间也缺少可持久化的视觉关系。

本功能在任务栏增加可永久保存的“联想”开关。开启后，用户在提示词中输入新的 `@`，即可直接拾取当前画板上的对象；引用随工作流提交，任务节点出现后立即建立来源连线，生成完成后再迁移到最终结果。

## 最终交互

1. 任务栏书籍按钮旁显示联想按钮。
2. 按钮默认关闭；点击开启后保存到浏览器本地，刷新和重新打开页面后保持状态。
3. 开启状态下，在任务栏提示词中逐键输入新的 `@`。
4. 画布进入拾取模式，用户点击一个可引用对象。
5. 原位置的 `@` 被替换为带类型编号的内联引用，例如：
   - `@图片1`
   - `@图片2`
   - `@视频1`
   - `@音频1`
   - `@文本1`
   - `@卡片1`
   - `@画框1`
6. 用户可继续输入正文并再次输入 `@`，引用多个来源。
7. 提交后，每个仍有效的引用来源都会连接到新任务节点；任务失败时连线仍保留。
8. 最终结果插入画布后，原关系线按工作流身份幂等迁移到第一个稳定结果，不额外生成第二组线。

## 输入与拾取规则

- 仅“新输入”的 `@` 进入画布拾取；粘贴、拖放、历史回填或外部脚本写入的 `@` 不会伪造画布对象身份。
- `@` 可位于任意正文位置，不要求前面为空格。
- 中文输入法组合输入结束后可正常触发，不在组合输入中途误触发。
- `Escape` 取消本次拾取并恢复输入焦点和原画布工具。
- 拾取期间强制使用选择工具，结束后恢复用户原来的画笔、手形或选择工具。
- 一次只拾取一个元素；可通过连续输入多个 `@` 引用多个来源。
- 同一来源在同一提示词中去重；不同来源按类型独立编号。
- 删除或改写完整引用 token 后，对应对象身份同步移除；仅看起来像 `@图片1` 的普通文本不会获得引用身份。
- 拾取点击不会再被普通画布选择链路二次消费，因此不会切换任务栏绑定草稿或只保留最后一个引用。

## 可引用对象与开放范围

支持当前画板中的图片、视频、音频、文本、图形、画框、卡片和其他普通业务元素。系统任务节点、生成锚点和联想关系线本身不作为来源，避免形成循环引用。

视觉类来源遵循以下开放规则：

- 不按来源元素数量拒绝。
- 不按来源逻辑宽高拒绝。
- 不按来源逻辑面积拒绝。
- 不按所选模型上传控件声明的推荐图片数量拒绝。
- 图片、卡片、画框和图形不会被客户端按数量截断。

资源边界由最终输出控制：多个引用串行解析；需要栅格化的完整来源按固定最长边和总像素预算自适应降采样，不裁剪来源逻辑边界，也不修改原画布对象。

以下安全与有效性检查仍保留：

- 来源必须仍存在于提交画板。
- 来源几何必须有限且尺寸有效。
- 模型明确完全不支持对应媒体类型时给出错误。
- 视频、音频引用继续校验模型所需的 URL 类型。
- Seedance 2.0 音频 Data URL 总量继续受 `16 MiB` 安全边界保护。
- 供应商最终仍可按自身能力拒绝请求；错误展示在任务节点，但引用身份和已经建立的关系线不丢失。

## 连线视觉与生命周期

联想关系线是带轻量元数据的 Plait 持久化元素，只管理本功能创建的关系线，不修改普通手绘连线。

最终样式：

- Plait 原生平滑曲线。
- 无起点、终点箭头。
- 黑色 `2px`，在浅色画布上保持清晰。
- 锁定，避免误选和误改。
- 左右不重叠时，从来源相向水平边连接到目标相向水平边。
- 横向范围重叠时，使用相向上下边。
- 多来源连接同一目标时形成自然汇聚，而不是生硬直线交叉。

旧版本创建的联想直线会在画板加载、端点移动或结果迁移时自动升级为当前曲线样式，迁移不写入撤销历史。

生命周期：

1. 预检成功并创建任务节点。
2. 使用提交前的不可变引用快照立即建立全部来源线，不等待异步提交返回。
3. 异步提交返回后再执行一次幂等建线，作为竞态恢复。
4. 任务失败或取消时，任务节点及关系线继续保留，便于重试和追踪。
5. 最终结果插入后，按 `workflowId` 将原线迁移到结果元素。
6. 来源或目标删除后，仅删除失去端点的关系线，另一个业务元素不受影响。
7. 来源或目标移动、缩放后，关系线重新计算相向边端点。

## 架构与数据流

```text
任务栏输入新 @
  -> CanvasAssociationTrigger
  -> SelectionWatcher 拾取元素 ID
  -> CanvasAssociationRef（画板、元素、类型、标签、文本范围）
  -> 提交前可信引用合并与不可变快照
  -> 串行解析为已有 SelectedContent
  -> Workflow metadata / AI context / SW context
  -> 创建 WorkZone 或图片生成锚点
  -> 立即创建持久化曲线
  -> 任务结果插入
  -> 按 workflowId 幂等迁移曲线
```

主要复用点：

- 复用任务栏现有提示词、草稿和生成类型状态。
- 复用 `SelectionWatcher`、Plait 选择工具及画布元素查找。
- 复用图片、视频、音频、文本和画布栅格化解析链路。
- 复用 `SelectedContent`、工作流 metadata、Service Worker 和重试上下文。
- 复用 WorkZone、图片生成锚点和最终结果插入流程。
- 复用 Plait `arrow-line` 持久化、操作监听和原生 `curve` 渲染。

## 持久化与权限边界

- 联想开关只写浏览器本地设置，不新增服务端账户权限。
- 提示词草稿只保存轻量引用 ID、类型、标签及可信文本范围。
- 关系线只保存版本、画板 ID、来源 ID、目标 ID、工作流 ID 和任务 ID。
- 不在引用或关系线中持久化 Base64、Blob、完整媒体二进制或 API Key。
- 提交仍走现有模型路由、供应商鉴权、Service Worker 和任务权限链路。
- 跨画板时禁止把来源线写入错误画板；已接受任务仅保留有界的延迟建线意图，回到来源画板后最多补一次。

## 性能与并发边界

- 引用数量上限保持为每个提示词 `20` 个唯一来源，用于限制持久化元数据和交互复杂度；这与模型图片数量限制无关。
- 多个大型来源串行解析，避免同时展开多份栅格输出。
- 输出位图最长边、总像素和采样比例受固定预算控制。
- 元素排序预建 ID 索引，避免在大量元素转换时反复线性查找。
- 建线、异步确认和结果通知均幂等；重复消息不会产生重复线。
- 并发工作流使用 `workflowId` 隔离，只迁移自己的关系线。
- 延迟建线意图最多保留 `256` 条，超出时淘汰最旧记录。

## 已知边界

- 已经丢失来源身份的历史任务无法仅凭可见 `@文字` 反推原元素，不自动追溯补线。
- 极端宽高比来源在固定输出预算下，短边可能低于 `1px`；逻辑范围仍完整保留。
- 超复杂来源的 DOM 克隆峰值仍随元素复杂度增长，当前仅保证多个引用串行和输出像素有界。
- 供应商可能拒绝超过其真实能力的输入数量；客户端不再提前截断或伪装成功。

## 一句话结论

开启联想后，提示词中的每个可信 `@对象` 都保留独立画布身份，完整进入任务并以持久化平滑曲线连接任务或最终结果，任务失败也不会丢失引用关系。
